# Operators in TypeScript

## 1. Summary

Operators are special symbols used in programming to perform operations on variables and values. In TypeScript, which is a superset of JavaScript, operators play a crucial role in manipulating data and controlling program flow. Understanding operators allows developers to perform mathematical calculations, comparisons, and logic operations, thereby enabling more complex behaviors in applications.

## 2. Code Examples

### 2.1 Bitwise Operators

Bitwise operators perform operations on binary representations of numbers. They can also be applied to strings after converting them to binary.

#### Example: Using Bitwise Operators with Numbers

```typescript
/**
 * Perform bitwise AND operation on two numbers.
 * @param {number} a - The first number.
 * @param {number} b - The second number.
 * @returns {number} - The result of the bitwise AND operation.
 */
function bitwiseAnd(a: number, b: number): number {
  return a & b; // Performs a bitwise AND operation
}

// Example usage
const result1 = bitwiseAnd(5, 3); // 5 in binary is 101, 3 is 011. Result is 001 (1 in decimal).
console.log(result1); // Output: 1
```

#### Example: Using Bitwise Operators with Strings

```typescript
/**
 * Convert a string to binary representation and perform bitwise OR operation with another string.
 * @param {string} str1 - The first string.
 * @param {string} str2 - The second string.
 * @returns {string} - The binary result of the bitwise OR operation.
 */
function bitwiseOrStrings(str1: string, str2: string): string {
  const binStr1 = str1
    .split('')
    .map((char) => char.charCodeAt(0))
    .reduce((acc, cur) => acc | cur);
  const binStr2 = str2
    .split('')
    .map((char) => char.charCodeAt(0))
    .reduce((acc, cur) => acc | cur);
  return (binStr1 | binStr2).toString(2); // Convert back to binary string
}

// Example usage
const result2 = bitwiseOrStrings('abc', 'xyz');
console.log(result2); // Output: Binary representation of the bitwise OR result
```

### 2.2 Nullish Coalescing (??) and Logical OR (||) Comparison

The `??` (nullish coalescing) operator returns the right-hand operand when the left-hand operand is `null` or `undefined`. In contrast, the `||` operator returns the right-hand operand when the left-hand operand is falsy (which includes values like `0`, `false`, `""`, `null`, and `undefined`).

#### Example: Nullish Coalescing vs Logical OR

```typescript
/**
 * Get a value with fallback using nullish coalescing and logical OR.
 * @param {number | null | undefined} input - The input value.
 * @returns {number} - The input value or a default value.
 */
function getValue(input: number | null | undefined): number {
  return input ?? 42; // Returns 42 if input is null or undefined
}

/**
 * Get a value with fallback using logical OR.
 * @param {number | null | undefined} input - The input value.
 * @returns {number} - The input value or a default value.
 */
function getValueOr(input: number | null | undefined): number {
  return input || 42; // Returns 42 if input is falsy (including 0)
}

// Example usage
console.log(getValue(null)); // Output: 42
console.log(getValue(0)); // Output: 0 (as 0 is neither null nor undefined)

console.log(getValueOr(null)); // Output: 42
console.log(getValueOr(0)); // Output: 42 (as 0 is falsy)
```

### 2.3 Other Operators Worth Covering

#### 2.3.1 Ternary Operator

The ternary operator (`? :`) allows for concise conditional expressions.

```typescript
/**
 * Check if a number is even or odd.
 * @param {number} num - The number to check.
 * @returns {string} - A string stating whether the number is even or odd.
 */
function isEvenOrOdd(num: number): string {
  return num % 2 === 0 ? 'Even' : 'Odd'; // Returns "Even" if true, else "Odd"
}

// Example usage
console.log(isEvenOrOdd(4)); // Output: Even
console.log(isEvenOrOdd(5)); // Output: Odd
```

## 3. TypeScript Built-in Support

TypeScript fully supports all JavaScript operators, including arithmetic, comparison, logical, bitwise, assignment, and ternary operators. TypeScript's type system adds additional safety checks, ensuring that operations are performed on compatible types.

## 4. Practical Use Case

Operators are essential in various scenarios, such as conditional rendering in React components. For example, using the nullish coalescing operator can simplify fallback logic for props or state variables, ensuring that default values are used when necessary:

```typescript
const MyComponent = ({ title }: { title?: string }) => {
  return <h1>{title ?? 'Default Title'}</h1>; // Renders Default Title if title is null or undefined
};
```

## 5. Common Mistakes and Best Practices

- **Mixing up `??` and `||`:** Be cautious not to confuse nullish coalescing with logical OR, as `||` can lead to unintended results for falsy values.
- **Operator Precedence:** Be aware of operator precedence to avoid logical errors in complex expressions.
- **Use parentheses for clarity:** When combining multiple operators, use parentheses to ensure that operations are performed in the intended order.
