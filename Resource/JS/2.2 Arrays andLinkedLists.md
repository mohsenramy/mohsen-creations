# Arrays & Linked Lists in TypeScript

## 1. Core Concept and Significance

### Arrays

- Arrays are ordered collections of elements with direct indexing, allowing for efficient access and manipulation. Arrays in TypeScript are dynamic, meaning they can change in size as elements are added or removed.
- Significance: Arrays are versatile and come with built-in methods that make them suitable for various use cases, including sorting, searching, and data transformation.

### Linked Lists

- A Linked List is a sequence of nodes where each node points to the next (and optionally previous) node, rather than being stored in contiguous memory locations. This makes linked lists efficient for frequent insertions and deletions.
- Significance: Linked lists are ideal for managing dynamic data where the size of the list changes frequently, and you require efficient insertions and deletions, especially from the middle of the list.

## 2. Code Examples and Built-In Array Functions

### Arrays in TypeScript

TypeScript arrays support various built-in methods for efficient data manipulation. Here’s a brief overview:

```typescript
let numbers: number[] = [10, 20, 30, 40, 50];

// Accessing elements
console.log(numbers[1]); // Output: 20

// Modifying elements
numbers[2] = 35;
console.log(numbers); // Output: [10, 20, 35, 40, 50]

// Array methods
numbers.push(60); // Adds to the end
numbers.pop(); // Removes from the end
numbers.shift(); // Removes from the start
numbers.unshift(5); // Adds to the start
numbers.splice(2, 0, 25); // Adds 25 at index 2
numbers.splice(3, 1); // Removes element at index 3
console.log(numbers); // Output: [5, 10, 25, 35, 50]
```

#### Common Array Methods:

- `.concat()`: Combines arrays.
- `.find()` and `.findIndex()`: Finds elements or their indices.
- `.filter()`: Creates a new array with elements that pass a test.
- `.map()`: Creates a new array with the results of a function on each element.
- `.reduce()`: Reduces array to a single value.
- `.slice()`: Extracts a section of an array.
- `.sort()`: Sorts the array in place.

These methods allow complex operations without the need for extensive looping.

### Singly Linked List Example

```typescript
class ListNode<T> {
  value: T;
  next: ListNode<T> | null = null;

  constructor(value: T) {
    this.value = value;
  }
}

class SinglyLinkedList<T> {
  head: ListNode<T> | null = null;

  append(value: T): void {
    const newNode = new ListNode(value);
    if (!this.head) {
      this.head = newNode;
    } else {
      let current = this.head;
      while (current.next) {
        current = current.next;
      }
      current.next = newNode;
    }
  }

  delete(value: T): void {
    if (!this.head) return;

    if (this.head.value === value) {
      this.head = this.head.next;
      return;
    }

    let current = this.head;
    while (current.next && current.next.value !== value) {
      current = current.next;
    }

    if (current.next) {
      current.next = current.next.next;
    }
  }

  search(value: T): ListNode<T> | null {
    let current = this.head;
    while (current) {
      if (current.value === value) return current;
      current = current.next;
    }
    return null;
  }
}
```

### Doubly Linked List Example with Search

```typescript
class DoublyListNode<T> {
  value: T;
  next: DoublyListNode<T> | null = null;
  prev: DoublyListNode<T> | null = null;

  constructor(value: T) {
    this.value = value;
  }
}

class DoublyLinkedList<T> {
  head: DoublyListNode<T> | null = null;
  tail: DoublyListNode<T> | null = null;

  append(value: T): void {
    const newNode = new DoublyListNode(value);
    if (!this.tail) {
      this.head = this.tail = newNode;
    } else {
      this.tail.next = newNode;
      newNode.prev = this.tail;
      this.tail = newNode;
    }
  }

  delete(value: T): void {
    let current = this.head;

    while (current) {
      if (current.value === value) {
        if (current.prev) current.prev.next = current.next;
        if (current.next) current.next.prev = current.prev;
        if (current === this.head) this.head = current.next;
        if (current === this.tail) this.tail = current.prev;
        break;
      }
      current = current.next;
    }
  }

  search(value: T): DoublyListNode<T> | null {
    let current = this.head;
    while (current) {
      if (current.value === value) return current;
      current = current.next;
    }
    return null;
  }
}
```

## 3. Practical Use Cases

1.  **Array-Based Stack/Queue Implementations**: Arrays are great for implementing stacks (LIFO) and queues (FIFO) where you can utilize .push() and .pop() for stacks, and .shift() and .push() for queues.
2.  **Navigating Forward and Backward**: Doubly linked lists are ideal for implementing history navigation (such as in a web browser), where you can move back and forth between states.
3.  **Building Dynamic Data Structures**: Linked lists are useful in applications where data structure needs to be dynamic, like a to-do list, where tasks are added or removed frequently.

## 4. Best Practices

1.  **Choose the Right Data Structure:**
    - Use Arrays when you need efficient access by index and less frequent data modification.
    - Use Linked Lists for frequent insertions/deletions and when the total number of elements is unknown or changes often.
2.  **Use Built-In Methods for Arrays**:
    - TypeScript provides extensive support for array manipulation through built-in methods. Use these instead of manual loops for more concise and readable code.
3.  **Avoid Overhead with Linked Lists**:
    - Linked lists consume more memory due to node references. They are less efficient for tasks requiring frequent random access, as they do not support direct indexing.
4.  **Consider Immutable Data Practices**:
    - For arrays, prefer creating new arrays rather than mutating existing ones with methods like .slice(), .concat(), or the spread operator ([...]). This reduces side effects and helps maintain clean code.
5.  **Prevent Memory Leaks in Linked Lists**:
    - Ensure nodes are properly dereferenced (especially in doubly linked lists) to prevent memory leaks. This is crucial when deleting nodes in large data structures.
