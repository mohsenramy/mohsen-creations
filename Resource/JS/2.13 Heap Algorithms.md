### Heap Algorithms in TypeScript

---

### 1. Core Concept and Significance

**Heap algorithms** revolve around the data structure known as a **heap**. A heap is a specialized binary tree-based structure that satisfies the **heap property**: in a **max-heap**, each parent node is greater than or equal to its child nodes, and in a **min-heap**, each parent node is less than or equal to its child nodes. Heaps are particularly useful for efficiently managing priority queues, finding the smallest or largest elements, and implementing heap sort.

#### Types of Heaps:

- **Max-Heap**: Parent nodes are always greater than or equal to their children.
- **Min-Heap**: Parent nodes are always smaller than or equal to their children.

### 2. Code Examples with JSDoc and Explanation

#### Example 1: Heap Data Structure in TypeScript

```typescript
/**
 * Class representing a Max Heap.
 */
class MaxHeap<T> {
  private heap: T[];

  constructor() {
    this.heap = [];
  }

  /**
   * Adds a new element to the heap.
   * @param {T} element - The element to be added.
   */
  insert(element: T): void {
    this.heap.push(element);
    this.heapifyUp();
  }

  /**
   * Removes and returns the maximum element from the heap.
   * @returns {T | undefined} - The maximum element or undefined if heap is empty.
   */
  extractMax(): T | undefined {
    if (this.heap.length === 0) return undefined;
    const max = this.heap[0];
    const end = this.heap.pop();
    if (this.heap.length > 0 && end !== undefined) {
      this.heap[0] = end;
      this.heapifyDown();
    }
    return max;
  }

  /**
   * Moves the last element up to maintain the heap property.
   */
  private heapifyUp(): void {
    let index = this.heap.length - 1;
    const element = this.heap[index];
    while (index > 0) {
      const parentIndex = Math.floor((index - 1) / 2);
      const parent = this.heap[parentIndex];
      if (element <= parent) break;
      this.heap[index] = parent;
      index = parentIndex;
    }
    this.heap[index] = element;
  }

  /**
   * Moves the root element down to maintain the heap property.
   */
  private heapifyDown(): void {
    let index = 0;
    const length = this.heap.length;
    const element = this.heap[0];

    while (true) {
      let leftChildIndex = 2 * index + 1;
      let rightChildIndex = 2 * index + 2;
      let swap = null;

      if (leftChildIndex < length) {
        const leftChild = this.heap[leftChildIndex];
        if (leftChild > element) swap = leftChildIndex;
      }

      if (rightChildIndex < length) {
        const rightChild = this.heap[rightChildIndex];
        if (
          (swap === null && rightChild > element) ||
          (swap !== null && rightChild > this.heap[swap])
        ) {
          swap = rightChildIndex;
        }
      }

      if (swap === null) break;
      this.heap[index] = this.heap[swap];
      index = swap;
    }
    this.heap[index] = element;
  }
}

// Example usage of MaxHeap
const heap = new MaxHeap<number>();
heap.insert(10);
heap.insert(20);
heap.insert(5);
console.log(heap.extractMax()); // Output: 20
```

#### Explanation:

This `MaxHeap` class implements a max-heap using an array. The two main methods, `insert` and `extractMax`, ensure that the heap property is maintained by using helper methods `heapifyUp` and `heapifyDown`. Insertion adds an element at the end of the heap and moves it up to the correct position, while extraction removes the root and repositions the remaining elements.

### 3. Heapsort: Sorting Using Heaps

**Heapsort** is an efficient comparison-based sorting algorithm that builds a heap out of the input data and then repeatedly extracts the maximum (or minimum, in the case of a min-heap) element to produce a sorted result.

#### Heapsort Algorithm in TypeScript

```typescript
/**
 * Heapsort using a max-heap.
 * @param {number[]} arr - The array to be sorted.
 * @returns {number[]} - The sorted array.
 */
function heapSort(arr: number[]): number[] {
  const heap = new MaxHeap<number>();

  // Step 1: Insert all elements into the heap
  for (const num of arr) {
    heap.insert(num);
  }

  // Step 2: Extract elements to form a sorted array
  const sortedArr: number[] = [];
  let max = heap.extractMax();
  while (max !== undefined) {
    sortedArr.unshift(max); // Insert at the beginning for ascending order
    max = heap.extractMax();
  }

  return sortedArr;
}

// Example usage of heapSort
const array = [3, 5, 1, 10, 2];
console.log(heapSort(array)); // Output: [1, 2, 3, 5, 10]
```

#### Explanation:

The `heapSort` function first inserts all elements into a max-heap. After that, it extracts the maximum element repeatedly, which produces a sorted array in ascending order.

### 4. Priority Queue: Implementing with Heaps

A **priority queue** is a data structure where each element has a priority, and elements with higher priority are served before lower-priority elements. Heaps are a perfect fit for implementing priority queues due to their efficient extraction of the highest (or lowest) priority element.

#### Priority Queue in TypeScript

```typescript
/**
 * Class representing a Priority Queue using a Min Heap.
 */
class PriorityQueue<T> {
  private heap: { element: T; priority: number }[] = [];

  /**
   * Adds an element with a given priority to the queue.
   * @param {T} element - The element to be added.
   * @param {number} priority - The priority of the element.
   */
  enqueue(element: T, priority: number): void {
    const newItem = { element, priority };
    this.heap.push(newItem);
    this.heapifyUp();
  }

  /**
   * Removes and returns the element with the highest priority.
   * @returns {T | undefined} - The element with the highest priority.
   */
  dequeue(): T | undefined {
    if (this.heap.length === 0) return undefined;
    const min = this.heap[0].element;
    const end = this.heap.pop();
    if (this.heap.length > 0 && end !== undefined) {
      this.heap[0] = end;
      this.heapifyDown();
    }
    return min;
  }

  // heapifyUp and heapifyDown similar to the MaxHeap above, adjusted for MinHeap logic.
}

// Example usage of PriorityQueue
const pq = new PriorityQueue<string>();
pq.enqueue('low', 3);
pq.enqueue('high', 1);
pq.enqueue('medium', 2);
console.log(pq.dequeue()); // Output: "high"
```

### 5. Heap Applications: Solving Problems

#### Finding the K Largest Elements

Heaps can efficiently solve problems like finding the k largest elements in an array by maintaining a min-heap of size k.

```typescript
/**
 * Finds the K largest elements from an array.
 * @param {number[]} nums - The input array.
 * @param {number} k - Number of largest elements to find.
 * @returns {number[]} - The K largest elements.
 */
function findKLargest(nums: number[], k: number): number[] {
  const minHeap = new MaxHeap<number>();

  for (const num of nums) {
    minHeap.insert(num);
    if (minHeap.length > k) {
      minHeap.extractMax();
    }
  }

  return minHeap;
}
```

### Best Practices:

1. **Use Heaps for Priority Management**: When priority or order of elements matters, heaps are highly efficient.
2. **Avoid Heapify in Tight Loops**: Repeated heapification in performance-sensitive areas can become a bottleneck.
