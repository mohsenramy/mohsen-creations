# Sorting Algorithms in TypeScript

## 1. Core Concept and Significance

Sorting algorithms are fundamental techniques for arranging data in a specified order, typically in ascending or descending order. They are essential for optimizing the performance of other algorithms (like search algorithms) and improving the efficiency of data processing tasks. Understanding different sorting algorithms allows developers to choose the most efficient one based on the context, such as the size of the dataset and the nature of the data.

### Why Sorting Algorithms Matter:

- **Efficiency**: Different algorithms have varying time and space complexities. Choosing the right algorithm can significantly improve performance.
- **Data Structure Optimization**: Many data structures rely on sorting for operations like searching, merging, and grouping.
- **Algorithm Design**: Understanding sorting algorithms is crucial for mastering more complex algorithms and data structures.

## 2. Code Examples

### Quick Sort

Quick Sort is a divide-and-conquer algorithm that sorts items by selecting a "pivot" element and partitioning the other elements into two sub-arrays, according to whether they are less than or greater than the pivot.

```typescript
/**
 * Quick Sort algorithm implementation.
 *
 * @param arr - The array to be sorted.
 * @returns The sorted array.
 */
function quickSort(arr: number[]): number[] {
  if (arr.length <= 1) {
    return arr; // Base case: an array of zero or one element is already sorted.
  }

  const pivot = arr[arr.length - 1]; // Choose the last element as the pivot.
  const left: number[] = []; // Elements less than the pivot.
  const right: number[] = []; // Elements greater than the pivot.

  for (let i = 0; i < arr.length - 1; i++) {
    if (arr[i] < pivot) {
      left.push(arr[i]); // Add to left if less than pivot.
    } else {
      right.push(arr[i]); // Add to right if greater than or equal to pivot.
    }
  }

  // Recursively sort the left and right arrays and concatenate results with the pivot.
  return [...quickSort(left), pivot, ...quickSort(right)];
}

// Example usage
const unsortedArray = [34, 7, 23, 32, 5, 62];
const sortedArray = quickSort(unsortedArray);
console.log(sortedArray); // Output: [5, 7, 23, 32, 34, 62]
```

### Merge Sort

Merge Sort is another divide-and-conquer algorithm that divides the array into halves, sorts each half, and then merges the sorted halves back together.

```typescript
/**
 * Merge Sort algorithm implementation.
 *
 * @param arr - The array to be sorted.
 * @returns The sorted array.
 */
function mergeSort(arr: number[]): number[] {
  if (arr.length <= 1) {
    return arr; // Base case: an array of zero or one element is already sorted.
  }

  const mid = Math.floor(arr.length / 2); // Find the middle index.
  const left = mergeSort(arr.slice(0, mid)); // Recursively sort the left half.
  const right = mergeSort(arr.slice(mid)); // Recursively sort the right half.

  return merge(left, right); // Merge the sorted halves.
}

/**
 * Helper function to merge two sorted arrays.
 *
 * @param left - The left sorted array.
 * @param right - The right sorted array.
 * @returns The merged sorted array.
 */
function merge(left: number[], right: number[]): number[] {
  const result: number[] = [];
  let i = 0; // Pointer for left array.
  let j = 0; // Pointer for right array.

  // Merge while there are elements in both arrays.
  while (i < left.length && j < right.length) {
    if (left[i] < right[j]) {
      result.push(left[i]);
      i++;
    } else {
      result.push(right[j]);
      j++;
    }
  }

  // Concatenate any remaining elements from both arrays.
  return result.concat(left.slice(i)).concat(right.slice(j));
}

// Example usage
const unsortedArray2 = [38, 27, 43, 3, 9, 82, 10];
const sortedArray2 = mergeSort(unsortedArray2);
console.log(sortedArray2); // Output: [3, 9, 10, 27, 38, 43, 82]
```

### Heap Sort

Heap Sort is a comparison-based sorting algorithm that uses a binary heap data structure. It first builds a max heap from the input data, then repeatedly extracts the maximum element from the heap and rebuilds the heap until all elements are sorted.

```typescript
/**
 * Heap Sort algorithm implementation.
 *
 * @param arr - The array to be sorted.
 * @returns The sorted array.
 */
function heapSort(arr: number[]): number[] {
  const n = arr.length;

  // Build a max heap.
  for (let i = Math.floor(n / 2) - 1; i >= 0; i--) {
    heapify(arr, n, i);
  }

  // One by one extract elements from the heap.
  for (let i = n - 1; i > 0; i--) {
    [arr[0], arr[i]] = [arr[i], arr[0]]; // Swap the root (max element) with the last element.
    heapify(arr, i, 0); // Rebuild the heap.
  }

  return arr; // The sorted array.
}

/**
 * Helper function to maintain the heap property.
 *
 * @param arr - The array to be heapified.
 * @param n - The size of the heap.
 * @param i - The index of the element to heapify.
 */
function heapify(arr: number[], n: number, i: number): void {
  let largest = i; // Initialize largest as root.
  const left = 2 * i + 1; // Left child index.
  const right = 2 * i + 2; // Right child index.

  // If left child is larger than root.
  if (left < n && arr[left] > arr[largest]) {
    largest = left;
  }

  // If right child is larger than largest so far.
  if (right < n && arr[right] > arr[largest]) {
    largest = right;
  }

  // If largest is not root.
  if (largest !== i) {
    [arr[i], arr[largest]] = [arr[largest], arr[i]]; // Swap.
    heapify(arr, n, largest); // Recursively heapify the affected subtree.
  }
}

// Example usage
const unsortedArray3 = [5, 3, 8, 4, 2];
const sortedArray3 = heapSort(unsortedArray3);
console.log(sortedArray3); // Output: [2, 3, 4, 5, 8]
```

## 3. TypeScript Built-in Support

TypeScript itself does not have built-in sorting algorithms, but it provides robust typing capabilities that can be used to implement sorting algorithms effectively. You can use TypeScript's type annotations and interfaces to enforce type safety, as shown in the code examples above.

The `Array` prototype in JavaScript provides a built-in method called `sort`, but it does not guarantee a stable sort or type safety, making custom implementations like those shown above often more suitable in TypeScript projects.

### Example of Built-in Sort

```typescript
const numbers = [10, 5, 100, 2];
numbers.sort((a, b) => a - b); // Sorting in ascending order
console.log(numbers); // Output: [2, 5, 10, 100]
```

## 5. Common Mistakes and Best Practices

### Common Mistakes

- **Not Considering Time Complexity**: Using inefficient algorithms (e.g., bubble sort) for large datasets can lead to performance issues.
- **Modifying Original Arrays**: Some algorithms modify the original array, which can lead to unexpected results. Be mindful of this and prefer to create copies if necessary.
- **Using Non-Comparative Sorts Incorrectly**: Misunderstanding the requirements of sorting (like sorting objects) can lead to incorrect implementations.

### Best Practices

- **Choose the Right Algorithm**: Consider the dataset size and characteristics (e.g., partially sorted data) to select the most efficient sorting algorithm.
- **Implement Stable Sorts Where Necessary**: If maintaining the relative order of equal elements is important, choose a stable sorting algorithm (like merge sort).
- **Use Type Annotations**: Ensure type safety by using TypeScript’s type annotations in your sorting functions.
