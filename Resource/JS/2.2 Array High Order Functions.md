### 1. Core Concept of Array Higher-Order Functions

Array Higher-Order Functions are powerful methods in JavaScript and TypeScript that allow developers to work with arrays more effectively. They take other functions as arguments (callbacks), enabling complex operations like transformation, filtering, and iteration in a clean, declarative way. They promote functional programming principles by encouraging the use of pure functions and immutability. These methods include commonly used functions like `map()`, `filter()`, `reduce()`, `forEach()`, `find()`, and `some()`.

### 2. Code Examples with JSDoc and Explanations

#### Primitive Array Example

```typescript
/**
 * Doubles each number in an array of primitive numbers.
 * @param {number[]} numbers - Array of numbers to be doubled.
 * @returns {number[]} New array with each number doubled.
 */
function doubleNumbers(numbers: number[]): number[] {
  return numbers.map((num) => num * 2);
}

const nums = [1, 2, 3, 4, 5];
const doubled = doubleNumbers(nums);
console.log(doubled); // Output: [2, 4, 6, 8, 10]
```

**Explanation:**

- The `map()` function is a classic example of a higher-order function. It transforms the array by applying the provided function (`num * 2`) to each element.
- This operation is _pure_ and does not mutate the original array but creates a new one.

#### Advanced Type Array Example

```typescript
// Defining an interface for a complex object type.
interface Employee {
  id: number;
  name: string;
  salary: number;
}

/**
 * Filters employees by salary.
 * @param {Employee[]} employees - Array of employee objects.
 * @param {number} minSalary - Minimum salary to filter employees.
 * @returns {Employee[]} Array of employees with salary above the threshold.
 */
function filterHighEarners(
  employees: Employee[],
  minSalary: number
): Employee[] {
  return employees.filter((employee) => employee.salary > minSalary);
}

const employees: Employee[] = [
  { id: 1, name: 'Alice', salary: 3000 },
  { id: 2, name: 'Bob', salary: 5000 },
  { id: 3, name: 'Charlie', salary: 4000 },
];

const highEarners = filterHighEarners(employees, 3500);
console.log(highEarners);
// Output: [{ id: 2, name: "Bob", salary: 5000 }, { id: 3, name: "Charlie", salary: 4000 }]
```

**Explanation:**

- The `filter()` function is used to filter out employees based on a salary condition. It returns a new array of employees whose salaries exceed the provided threshold.
- The function ensures the original array remains unmodified, promoting immutability.

#### Reduce Example

```typescript
/**
 * Calculates the total salary of all employees.
 * @param {Employee[]} employees - Array of employee objects.
 * @returns {number} Total salary of all employees.
 */
function totalSalary(employees: Employee[]): number {
  return employees.reduce((total, employee) => total + employee.salary, 0);
}

const total = totalSalary(employees);
console.log(total); // Output: 12000
```

**Explanation:**

- `reduce()` is a more advanced higher-order function used to accumulate values. It iterates over each item and updates the total, starting from an initial value (in this case, 0).

### 3. TypeScript Built-in Support

TypeScript provides built-in type support for higher-order functions in arrays, ensuring strong type-checking and preventing runtime errors:

- When using `map()`, `filter()`, and `reduce()`, TypeScript infers the types of the array elements and the result based on the callback function and array type.
- In the advanced array example, TypeScript ensures that only `Employee[]` can be passed, and the resulting array retains the same `Employee` type.

#### Type Inference with Primitive Arrays

```typescript
const numbers = [1, 2, 3, 4, 5];
const doubledNumbers = numbers.map((num) => num * 2); // TypeScript infers number[] for the result
```

#### Type Inference with Advanced Arrays

```typescript
const employeeNames = employees.map((employee) => employee.name); // TypeScript infers string[] for the result
```

### 4. Practical Use Case

Higher-order functions are highly useful in scenarios where arrays need to be transformed or filtered. For example, in a financial application where multiple transactions need to be processed, higher-order functions can simplify calculations like summing totals, filtering for specific conditions, or transforming data formats.

**Scenario: Employee Payroll Calculation**

- You may need to filter employees based on their roles, map their data to generate a report, and then use `reduce()` to calculate total payroll expenses.

### 5. Common Mistakes and Best Practices

#### Common Mistakes:

- **Mutating the Original Array:** Functions like `map()`, `filter()`, and `reduce()` return new arrays but do not modify the original array. Developers might assume they modify the original data, leading to unintended side effects.

  **Example of Mistake:**

  ```typescript
  const modifiedArray = numbers.map((num) => num * 2); // The original array remains unchanged.
  ```

- **Using the Wrong Function:** Misunderstanding the behavior of different higher-order functions can lead to incorrect usage. For instance, using `forEach()` when you need `map()` (which returns a value) or using `map()` for side effects instead of transformations.

#### Best Practices:

- **Immutability:** Always rely on the new array returned by functions like `map()` and `filter()` rather than modifying the original array.

  ```typescript
  // Good practice: Use the returned array.
  const newArray = originalArray.map(fn);
  ```

- **Using Arrow Functions for Concise Code:** Arrow functions provide a cleaner, more concise syntax, especially when the callback is simple.

  ```typescript
  // Good
  const result = nums.map((n) => n * 2);
  ```

Higher-order functions on arrays are crucial in JavaScript and TypeScript, offering powerful tools for transforming, filtering, and reducing data in a functional way. By understanding how to use these methods properly, including leveraging TypeScript's type safety, developers can write more readable, concise, and efficient code.
