### Dynamic Programming with Recursion in TypeScript

#### 1. Summary

**Dynamic Programming (DP)** is a method for solving complex problems by breaking them down into simpler subproblems. It optimizes recursive algorithms by storing the results of expensive function calls and reusing them when the same inputs occur again, thereby reducing redundant calculations. DP is particularly powerful when applied to problems with overlapping subproblems and optimal substructure properties.

Dynamic Programming typically involves two main techniques:

- **Memoization**: A top-down approach where intermediate results are stored to avoid recalculating them.
- **Tabulation**: A bottom-up approach where we build a table of results iteratively.

Both techniques are often used to optimize recursive solutions and are particularly useful in problems like the Fibonacci sequence, the knapsack problem, or shortest path algorithms.

#### 2. Code Examples

##### Example 1: Fibonacci Sequence with Memoization

```typescript
/**
 * Calculates the nth Fibonacci number using dynamic programming (memoization).
 * @param n - The index of the Fibonacci sequence to compute.
 * @param memo - An array used to store previously calculated Fibonacci numbers.
 * @returns The nth Fibonacci number.
 */
function fibonacciMemo(n: number, memo: number[] = []): number {
  if (n <= 1) return n;

  // If the value has already been calculated, return it from memo
  if (memo[n] !== undefined) return memo[n];

  // Recursively calculate and store the result in the memo array
  memo[n] = fibonacciMemo(n - 1, memo) + fibonacciMemo(n - 2, memo);
  return memo[n];
}

console.log(fibonacciMemo(10)); // Output: 55
```

In this example, the `fibonacciMemo` function uses memoization to store previously computed Fibonacci numbers in an array called `memo`. If the result for a particular `n` is already in the memo array, it is returned without further computation. Otherwise, the function recursively calculates the Fibonacci number and stores it.

##### Example 2: Fibonacci Sequence with Tabulation

```typescript
/**
 * Calculates the nth Fibonacci number using dynamic programming (tabulation).
 * @param n - The index of the Fibonacci sequence to compute.
 * @returns The nth Fibonacci number.
 */
function fibonacciTabulation(n: number): number {
  if (n <= 1) return n;

  // Create a table to store Fibonacci values
  const table: number[] = [0, 1];

  // Fill the table iteratively
  for (let i = 2; i <= n; i++) {
    table[i] = table[i - 1] + table[i - 2];
  }

  return table[n];
}

console.log(fibonacciTabulation(10)); // Output: 55
```

In the tabulation approach, a table is built up iteratively to store the Fibonacci values from the base case upwards. This eliminates the need for recursion and is more space-efficient than memoization.

##### Example 3: Knapsack Problem with Recursion and Memoization

The **Knapsack Problem** is a classic dynamic programming problem where you need to maximize the value of items in a knapsack with a given weight limit.

```typescript
/**
 * Solves the knapsack problem using recursion and memoization.
 * @param weights - Array of item weights.
 * @param values - Array of item values.
 * @param capacity - Maximum capacity of the knapsack.
 * @param n - Number of items.
 * @param memo - A 2D array for storing intermediate results.
 * @returns Maximum value that can be achieved with the given capacity.
 */
function knapsackMemo(
  weights: number[],
  values: number[],
  capacity: number,
  n: number,
  memo: number[][] = []
): number {
  // Base case: no items or capacity
  if (n === 0 || capacity === 0) return 0;

  // Initialize memo if not done already
  if (!memo[n]) memo[n] = [];

  // Return memoized value if already computed
  if (memo[n][capacity] !== undefined) return memo[n][capacity];

  // If the weight of the nth item is more than the capacity, skip this item
  if (weights[n - 1] > capacity) {
    return (memo[n][capacity] = knapsackMemo(
      weights,
      values,
      capacity,
      n - 1,
      memo
    ));
  }

  // Recursively choose to include or exclude the nth item
  const includeItem =
    values[n - 1] +
    knapsackMemo(weights, values, capacity - weights[n - 1], n - 1, memo);
  const excludeItem = knapsackMemo(weights, values, capacity, n - 1, memo);

  // Store the result in memo
  return (memo[n][capacity] = Math.max(includeItem, excludeItem));
}

// Test case
const weights = [1, 3, 4, 5];
const values = [1, 4, 5, 7];
const capacity = 7;
console.log(knapsackMemo(weights, values, capacity, weights.length)); // Output: 9
```

This solution uses memoization to solve the knapsack problem by storing intermediate results in a 2D array `memo`. The function recursively considers whether to include or exclude an item based on its weight and value.

#### 3. TypeScript Built-In Support

TypeScript does not have built-in support specifically for dynamic programming, but its **type system** provides powerful features like **type inference** and **strict type checking**. These features ensure that recursive functions and memoization structures (e.g., arrays, objects) are typed correctly. TypeScript's ability to define types for complex data structures (like the memoization table in the knapsack problem) enhances code safety and readability in dynamic programming.

For example, defining memoization tables with proper types in recursive algorithms ensures that you don't accidentally misuse them, which can be hard to detect in plain JavaScript.

#### 4. Practical Use Cases

Dynamic programming is often used in:

- **Optimization Problems**: Problems where you want to find the maximum/minimum value (e.g., knapsack problem, coin change problem).
- **Combinatorics**: Calculating binomial coefficients or paths in a grid.
- **Sequence Analysis**: Problems like finding the longest increasing subsequence, or determining the edit distance between two strings (Levenshtein distance).
- **Fibonacci Sequence**: A classic case where dynamic programming reduces exponential time complexity to linear time complexity.

#### 5. Common Mistakes and Best Practices

- **Avoid Redundant Computation**: Always memoize results in recursive problems to avoid recomputation.
- **Use Tabulation for Iterative Solutions**: If your problem can be broken down into smaller subproblems solved in sequence, use tabulation (bottom-up) instead of recursion, as it's often more memory-efficient.
- **Understand Problem Structure**: Not all problems benefit from dynamic programming. Make sure the problem has overlapping subproblems and an optimal substructure.
- **Edge Cases**: Be mindful of edge cases like base cases in recursion (e.g., when `n = 0` or `capacity = 0` in the knapsack problem).

#### Memoization vs Tabulation

- **Memoization**: This is a top-down approach, where you start from the main problem and recursively solve subproblems, storing the results of each.
  - Example: Fibonacci with memoization.
- **Tabulation**: This is a bottom-up approach, where you iteratively solve all subproblems and build up a solution to the main problem.
  - Example: Fibonacci with tabulation.

Memoization is easier to implement if you're converting a basic recursive solution into a DP solution. Tabulation is more efficient in terms of memory because it doesn't require the overhead of recursion.
