# Graph Algorithms in TypeScript

## 1. Core Concept and Significance

Graphs are one of the most fundamental data structures in computer science, consisting of **nodes (vertices)** connected by **edges**. They are used to model real-world scenarios such as social networks, transportation systems, and communication networks. Graph algorithms help solve a wide variety of problems, including finding the shortest path, determining connectivity, and detecting cycles.

In this guide, we will cover:

- **Graph Traversal**: DFS, BFS, and cycle detection.
- **Shortest Path Algorithms**: Dijkstra’s and Bellman-Ford algorithms.
- **Graph Connectivity**: Connected components and strongly connected components.
- **Topological Sorting**: Sorting in Directed Acyclic Graphs (DAGs).

## 2. Graph Traversal Revisited: DFS, BFS, and Cycle Detection

Graph traversal refers to visiting nodes in a graph in a systematic way. Two common methods are **Depth-First Search (DFS)** and **Breadth-First Search (BFS)**.

### Depth-First Search (DFS)

DFS explores as far as possible along a branch before backtracking. It uses a **stack** or recursion.

```typescript
/**
 * Performs Depth-First Search on a graph.
 * @param {Map<number, number[]>} graph - The adjacency list representing the graph.
 * @param {number} start - The starting vertex for DFS.
 * @returns {number[]} The order of visited nodes.
 */
function dfs(graph: Map<number, number[]>, start: number): number[] {
  const visited = new Set<number>();
  const result: number[] = [];

  function dfsHelper(v: number) {
    if (visited.has(v)) return;
    visited.add(v);
    result.push(v);

    for (const neighbor of graph.get(v) || []) {
      dfsHelper(neighbor);
    }
  }

  dfsHelper(start);
  return result;
}

// Example usage:
const graph = new Map([
  [1, [2, 3]],
  [2, [4]],
  [3, [5]],
  [4, []],
  [5, []],
]);

console.log(dfs(graph, 1)); // Output: [1, 2, 4, 3, 5]
```

### Breadth-First Search (BFS)

BFS explores all neighbors at the present depth before moving on to nodes at the next depth level. It uses a **queue**.

```typescript
/**
 * Performs Breadth-First Search on a graph.
 * @param {Map<number, number[]>} graph - The adjacency list representing the graph.
 * @param {number} start - The starting vertex for BFS.
 * @returns {number[]} The order of visited nodes.
 */
function bfs(graph: Map<number, number[]>, start: number): number[] {
  const visited = new Set<number>();
  const queue: number[] = [start];
  const result: number[] = [];

  while (queue.length > 0) {
    const node = queue.shift()!;
    if (!visited.has(node)) {
      visited.add(node);
      result.push(node);
      queue.push(...(graph.get(node) || []));
    }
  }

  return result;
}

// Example usage:
console.log(bfs(graph, 1)); // Output: [1, 2, 3, 4, 5]
```

### Cycle Detection in Graphs

Detecting cycles is crucial, especially in directed graphs (e.g., to avoid infinite loops).

For cycle detection in **DFS**, a back edge points to an ancestor in the recursion stack.

```typescript
/**
 * Detects if a cycle exists in a directed graph using DFS.
 * @param {Map<number, number[]>} graph - The adjacency list of the graph.
 * @returns {boolean} True if a cycle is detected, false otherwise.
 */
function hasCycle(graph: Map<number, number[]>): boolean {
  const visited = new Set<number>();
  const recStack = new Set<number>();

  function dfsHelper(v: number): boolean {
    if (recStack.has(v)) return true;
    if (visited.has(v)) return false;

    visited.add(v);
    recStack.add(v);

    for (const neighbor of graph.get(v) || []) {
      if (dfsHelper(neighbor)) return true;
    }

    recStack.delete(v);
    return false;
  }

  for (const node of graph.keys()) {
    if (dfsHelper(node)) return true;
  }

  return false;
}

// Example usage:
console.log(hasCycle(graph)); // Output: false (for the provided graph)
```

## 3. Shortest Path Algorithms

### Dijkstra's Algorithm

Dijkstra's algorithm finds the shortest path from a source node to all other nodes in a **weighted graph** with non-negative weights.

```typescript
/**
 * Implements Dijkstra's algorithm for shortest paths.
 * @param {Map<number, [number, number][]>} graph - Graph represented as adjacency list (node, weight).
 * @param {number} start - The starting node.
 * @returns {Map<number, number>} The shortest distance from start to each node.
 */
function dijkstra(
  graph: Map<number, [number, number][]>,
  start: number
): Map<number, number> {
  const distances = new Map<number, number>();
  const visited = new Set<number>();
  const priorityQueue: [number, number][] = [[start, 0]]; // [node, distance]

  graph.forEach((_, node) => distances.set(node, Infinity));
  distances.set(start, 0);

  while (priorityQueue.length > 0) {
    const [node, distance] = priorityQueue.shift()!;
    if (visited.has(node)) continue;
    visited.add(node);

    for (const [neighbor, weight] of graph.get(node) || []) {
      const newDist = distance + weight;
      if (newDist < (distances.get(neighbor) || Infinity)) {
        distances.set(neighbor, newDist);
        priorityQueue.push([neighbor, newDist]);
      }
    }
  }

  return distances;
}

// Example usage:
const weightedGraph = new Map([
  [
    1,
    [
      [2, 1],
      [3, 4],
    ],
  ],
  [
    2,
    [
      [3, 2],
      [4, 6],
    ],
  ],
  [3, [[4, 3]]],
  [4, []],
]);

console.log(dijkstra(weightedGraph, 1)); // Output: Map { 1 => 0, 2 => 1, 3 => 3, 4 => 6 }
```

### Bellman-Ford Algorithm

Bellman-Ford handles graphs with **negative weights** but is slower than Dijkstra.

```typescript
/**
 * Bellman-Ford algorithm to find the shortest path.
 * @param {Map<number, [number, number][]>} graph - Graph represented as adjacency list.
 * @param {number} start - The starting node.
 * @returns {Map<number, number>} The shortest distance from start to each node.
 */
function bellmanFord(
  graph: Map<number, [number, number][]>,
  start: number
): Map<number, number> {
  const distances = new Map<number, number>();
  graph.forEach((_, node) => distances.set(node, Infinity));
  distances.set(start, 0);

  for (let i = 0; i < graph.size - 1; i++) {
    for (const [node, edges] of graph) {
      for (const [neighbor, weight] of edges) {
        const currentDist = distances.get(node)!;
        const newDist = currentDist + weight;
        if (newDist < distances.get(neighbor)!) {
          distances.set(neighbor, newDist);
        }
      }
    }
  }

  // Check for negative weight cycles
  for (const [node, edges] of graph) {
    for (const [neighbor, weight] of edges) {
      if (distances.get(node)! + weight < distances.get(neighbor)!) {
        throw new Error('Graph contains a negative weight cycle');
      }
    }
  }

  return distances;
}

// Example usage:
console.log(bellmanFord(weightedGraph, 1)); // Output: Map { 1 => 0, 2 => 1, 3 => 3, 4 => 6 }
```

## 4. Graph Connectivity: Connected Components and Strongly Connected Components

### Connected Components in Undirected Graphs

A **connected component** is a set of nodes such that there is a path between any pair of nodes in that set.

```typescript
/**
 * Finds connected components in an undirected graph.
 * @param {Map<number, number[]>} graph - Graph represented as adjacency list.
 * @returns {number[][]} A list of connected components.
 */
function findConnectedComponents(graph: Map<number, number[]>): number[][] {
  const visited = new Set<number>();
  const components: number[][] = [];

  function dfs(node: number, component: number[]) {
    visited.add(node);
    component.push(node);
    for (const neighbor of graph.get(node) || []) {
      if (!visited.has(neighbor)) {
        dfs(neighbor, component);
      }
    }
  }

  for (const node of graph.keys()) {
    if (!visited.has(node)) {
      const component: number[] = [];
      dfs(node, component);
      components.push(component);
    }
  }

  return components;
}
```

## 5. Topological Sorting: Sorting in Directed Acyclic Graphs (DAGs)

Topological sorting of a **DAG** is a linear ordering of its vertices such that for every directed edge `uv`, vertex `u` comes before `v`.

```typescript
/**
 * Topological sorting using DFS for Directed Acyclic Graphs (DAG).
 * @param {Map<number, number[]>} graph - The DAG as an adjacency list.
 * @returns {number[]} The topologically sorted vertices.
 */
function topologicalSort(graph: Map<number, number[]>): number[] {
  const visited = new Set<number>();
  const result: number[] = [];

  function dfs(node: number) {
    if (visited.has(node)) return;
    visited.add(node);
    for (const neighbor of graph.get(node) || []) {
      dfs(neighbor);
    }
    result.push(node);
  }

  for (const node of graph.keys()) {
    if (!visited.has(node)) {
      dfs(node);
    }
  }

  return result.reverse();
}

// Example usage:
const dag = new Map([
  [5, [0, 2]],
  [4, [0, 1]],
  [3, [1]],
  [2, []],
  [1, []],
  [0, []],
]);

console.log(topologicalSort(dag)); // Output: [3, 4, 5, 1, 0, 2]
```

## Practical Use Case

- **Navigation Systems**: Graph algorithms like Dijkstra's or Bellman-Ford can be used in GPS navigation to find the shortest route between two locations on a map.
- **Dependency Resolution**: Topological sorting is widely used in build systems (like Make) to determine the order in which files should be compiled based on their dependencies.
- **Social Networks**: DFS and BFS can help find connected components, recommend friends, or suggest people in the same connected component.

## Common Mistakes and Best Practices

1. **Mistake**: Using Dijkstra's algorithm with negative weights (use Bellman-Ford instead).
2. **Best Practice**: Always check for cycles in a graph before performing operations like topological sorting, as it is only valid for DAGs.
3. **Tip**: Use adjacency lists for sparse graphs and adjacency matrices for dense graphs.
