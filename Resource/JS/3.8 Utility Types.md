### Advanced TypeScript Utility Types

TypeScript provides several **utility types** that help simplify common type transformations. These built-in types make it easier to manipulate and transform types while ensuring type safety. In this guide, we'll cover all the key utility types, including `Partial`, `Required`, `Readonly`, `Pick`, `Omit`, `Record`, `Exclude`, `Extract`, `NonNullable`, `ReturnType`, `InstanceType`, and `Awaited`.

---

### 1. **`Partial<T>`**

The `Partial` utility type constructs a type by making all properties of the input type `T` optional. It is useful when you want to update only a few properties of an object without specifying all properties.

```typescript
interface User {
  name: string;
  age: number;
  email: string;
}

/**
 * Function that updates user info with only partial details
 * @param {Partial<User>} userDetails - An object that can have any combination of user properties.
 */
function updateUser(userDetails: Partial<User>) {
  // You can now pass an object with one or more optional fields
  console.log(userDetails);
}

updateUser({ name: 'Alice' }); // Only 'name' provided
```

---

### 2. **`Required<T>`**

The `Required` utility type makes all properties of `T` mandatory, even if they were optional in the original type.

```typescript
interface User {
  name: string;
  age?: number;
}

/**
 * Function that requires all user properties to be present.
 * @param {Required<User>} userDetails - An object where all properties must be provided.
 */
function createUser(userDetails: Required<User>) {
  console.log(userDetails);
}

createUser({ name: 'Alice', age: 30 }); // 'age' is now mandatory
```

---

### 3. **`Readonly<T>`**

The `Readonly` utility type makes all properties of `T` immutable. You cannot modify the properties once they have been set.

```typescript
interface User {
  name: string;
  age: number;
}

/**
 * Function that accepts a readonly user object.
 * @param {Readonly<User>} user - A user object with immutable properties.
 */
function printUser(user: Readonly<User>) {
  console.log(user.name);
  // user.name = "Bob"; // Error: Cannot assign to 'name' because it is a read-only property.
}

const user: Readonly<User> = { name: 'Alice', age: 30 };
printUser(user);
```

---

### 4. **`Pick<T, K>`**

The `Pick` utility type creates a new type by selecting specific properties from `T`. This is useful when you need only a subset of the properties.

```typescript
interface User {
  name: string;
  age: number;
  email: string;
}

/**
 * Function that accepts only selected user details.
 * @param {Pick<User, "name" | "email">} user - Object with only selected properties.
 */
function displayUserContact(user: Pick<User, 'name' | 'email'>) {
  console.log(`User: ${user.name}, Email: ${user.email}`);
}

displayUserContact({ name: 'Alice', email: 'alice@example.com' });
```

---

### 5. **`Omit<T, K>`**

The `Omit` utility type constructs a type by excluding specific properties from `T`. This is the opposite of `Pick`.

```typescript
interface User {
  name: string;
  age: number;
  email: string;
}

/**
 * Function that displays user info without showing their age.
 * @param {Omit<User, "age">} user - Object with 'age' excluded.
 */
function displayUserInfo(user: Omit<User, 'age'>) {
  console.log(user.name, user.email);
}

displayUserInfo({ name: 'Alice', email: 'alice@example.com' });
```

---

### 6. **`Record<K, T>`**

The `Record` utility type creates an object type with keys of type `K` and values of type `T`. It’s often used to create maps or dictionaries.

```typescript
type Role = 'admin' | 'user';
type Permissions = { canEdit: boolean; canDelete: boolean };

/**
 * Function that maps roles to their permissions.
 * @param {Record<Role, Permissions>} rolePermissions - A record of roles to permissions.
 */
const rolePermissions: Record<Role, Permissions> = {
  admin: { canEdit: true, canDelete: true },
  user: { canEdit: false, canDelete: false },
};

console.log(rolePermissions);
```

---

### 7. **`Exclude<T, U>`**

The `Exclude` utility type removes all union members from `T` that are assignable to `U`.

```typescript
type Status = 'success' | 'error' | 'pending';
type NonPendingStatus = Exclude<Status, 'pending'>; // "success" | "error"

/**
 * Function that accepts non-pending statuses.
 * @param {NonPendingStatus} status - A status that is not 'pending'.
 */
function handleStatus(status: NonPendingStatus) {
  console.log(`Handling status: ${status}`);
}

handleStatus('success');
```

---

### 8. **`Extract<T, U>`**

The `Extract` utility type extracts all union members from `T` that are assignable to `U`. It’s the opposite of `Exclude`.

```typescript
type Status = 'success' | 'error' | 'pending';
type SuccessOrError = Extract<Status, 'success' | 'error'>; // "success" | "error"

/**
 * Function that only accepts 'success' or 'error' statuses.
 * @param {SuccessOrError} status - Either 'success' or 'error'.
 */
function processStatus(status: SuccessOrError) {
  console.log(`Processing: ${status}`);
}

processStatus('error');
```

---

### 9. **`NonNullable<T>`**

The `NonNullable` utility type removes `null` and `undefined` from `T`.

```typescript
type Name = string | null | undefined;
type NonNullableName = NonNullable<Name>; // string

/**
 * Function that only accepts non-nullable names.
 * @param {NonNullableName} name - A valid name that is not null or undefined.
 */
function greet(name: NonNullableName) {
  console.log(`Hello, ${name}`);
}

greet('Alice');
```

---

### 10. **`ReturnType<T>`**

The `ReturnType` utility type extracts the return type of a function.

```typescript
function getUser() {
  return { name: 'Alice', age: 30 };
}

type UserReturnType = ReturnType<typeof getUser>; // { name: string, age: number }

/**
 * Function that processes a returned user.
 * @param {UserReturnType} user - User object returned from getUser().
 */
function processUser(user: UserReturnType) {
  console.log(user.name, user.age);
}

processUser(getUser());
```

---

### 11. **`InstanceType<T>`**

The `InstanceType` utility type extracts the type of the instance of a class or constructor function.

```typescript
class User {
  name = 'Alice';
  age = 30;
}

type UserInstance = InstanceType<typeof User>; // User

/**
 * Function that processes an instance of the User class.
 * @param {UserInstance} user - An instance of the User class.
 */
function printUserInstance(user: UserInstance) {
  console.log(user.name, user.age);
}

printUserInstance(new User());
```

---

### 12. **`Awaited<T>`**

The `Awaited` utility type extracts the type of the resolved value of a `Promise`.

```typescript
async function fetchData(): Promise<string> {
  return 'Data fetched';
}

type FetchedDataType = Awaited<ReturnType<typeof fetchData>>; // string

/**
 * Function that processes the fetched data.
 * @param {FetchedDataType} data - The resolved value from fetchData().
 */
async function processData(data: FetchedDataType) {
  console.log(data);
}

processData(await fetchData());
```

---

## Conclusion

TypeScript’s utility types offer powerful ways to manipulate and work with types. They allow developers to handle complex type transformations and enforce stricter type safety. Understanding and using these utility types correctly can make your code more flexible, maintainable, and type-safe.
