### 1. Core Concept & Significance

**Looping and conditional statements** are essential constructs in TypeScript (and JavaScript) that allow for dynamic control of program flow. Conditional statements enable you to execute different pieces of code based on certain conditions, while looping allows repetitive execution of code blocks until a specific condition is met. These constructs are fundamental to decision-making and iteration, driving the logic behind most applications.

### 2. Code Examples with JSDoc and Comments

#### **Conditional Statements**

##### **if/else**

```typescript
/**
 * Checks if a number is positive, negative, or zero.
 * @param num - The number to check.
 * @returns A string indicating whether the number is positive, negative, or zero.
 */
function checkNumber(num: number): string {
  if (num > 0) {
    return 'Positive';
  } else if (num < 0) {
    return 'Negative';
  } else {
    return 'Zero';
  }
}

console.log(checkNumber(5)); // Output: Positive
console.log(checkNumber(-2)); // Output: Negative
console.log(checkNumber(0)); // Output: Zero
```

- **Explanation**: The `if` statement checks the condition (`num > 0`) first. If true, the corresponding block runs. If false, it moves to the next `else if` condition, and if all conditions fail, the `else` block executes.

##### **switch**

```typescript
/**
 * Returns a greeting based on the input day of the week.
 * @param day - The day of the week.
 * @returns A string with a greeting message.
 */
function getGreeting(day: string): string {
  switch (day) {
    case 'Monday':
      return 'Start of the week!';
    case 'Friday':
      return 'Almost the weekend!';
    case 'Saturday':
    case 'Sunday':
      return 'Enjoy your weekend!';
    default:
      return 'Have a great day!';
  }
}

console.log(getGreeting('Friday')); // Output: Almost the weekend!
console.log(getGreeting('Tuesday')); // Output: Have a great day!
```

- **Explanation**: The `switch` statement evaluates the expression `day`. It compares the value of `day` to the values specified in each `case` and runs the corresponding block. If no match is found, the `default` block executes.

#### **Looping Constructs**

##### **for loop**

```typescript
/**
 * Sums the numbers from 1 to a given number.
 * @param n - The limit number.
 * @returns The sum of numbers from 1 to `n`.
 */
function sumNumbers(n: number): number {
  let sum = 0;
  for (let i = 1; i <= n; i++) {
    sum += i; // Adds i to the current sum
  }
  return sum;
}

console.log(sumNumbers(5)); // Output: 15
```

- **Explanation**: A `for` loop iterates over a sequence. Here, it sums numbers from 1 to `n`. The loop runs while the condition `i <= n` is true.

##### **while loop**

```typescript
/**
 * Logs all even numbers up to a given limit.
 * @param limit - The upper limit number.
 */
function logEvenNumbers(limit: number): void {
  let i = 0;
  while (i <= limit) {
    if (i % 2 === 0) {
      console.log(i);
    }
    i++; // Increment after each loop iteration
  }
}

logEvenNumbers(10); // Output: 0, 2, 4, 6, 8, 10
```

- **Explanation**: The `while` loop runs as long as the condition (`i <= limit`) is true. It logs even numbers by checking the modulus (`i % 2 === 0`).

##### **do-while loop**

```typescript
/**
 * Prints numbers starting from 1 until a given limit.
 * @param limit - The upper limit number.
 */
function printNumbers(limit: number): void {
  let i = 1;
  do {
    console.log(i); // Print the number before increment
    i++;
  } while (i <= limit);
}

printNumbers(5); // Output: 1, 2, 3, 4, 5
```

- **Explanation**: A `do-while` loop ensures the code block runs at least once before checking the condition (`i <= limit`).

##### **for...of loop**

```typescript
/**
 * Logs each item in an array.
 * @param arr - The array of items to log.
 */
function logArrayItems(arr: string[]): void {
  for (const item of arr) {
    console.log(item);
  }
}

logArrayItems(['apple', 'banana', 'cherry']); // Output: apple, banana, cherry
```

- **Explanation**: The `for...of` loop iterates over elements in an array. It's best used when you only need the values, not the indices.

### `forEach` in TypeScript

The `forEach` method is a higher-order function available on arrays in TypeScript (and JavaScript). It's used to execute a provided function once for each array element, making it useful for performing side effects like logging, modifying DOM elements, or performing other actions without explicitly managing iteration logic.

Unlike traditional loops, `forEach` does not return a new array or allow the use of `break` or `return` to exit early. It's typically used when you need to iterate through an array and execute code on each element, but you're not trying to modify the array or control the flow.

### Example of `forEach`

```typescript
/**
 * Logs each name in an array of names.
 * @param names - The array of names.
 */
function logNames(names: string[]): void {
  names.forEach((name: string) => {
    console.log(name);
  });
}

logNames(['Alice', 'Bob', 'Charlie']); // Output: Alice, Bob, Charlie
```

- **Explanation**: `forEach` iterates over each element in the `names` array and executes the callback function, logging each name.

### Comparing `forEach` to Other Loops

- **No Early Exit**: You cannot use `break` or `return` inside a `forEach`. It will always iterate over the entire array.
- **Mutability**: `forEach` is commonly used for actions that don't require modifying the array. If you need to create a new array or modify the existing one, prefer `map`, `filter`, or `reduce`.

```typescript
const numbers = [1, 2, 3];
numbers.forEach((num) => {
  if (num === 2) {
    return; // This will only return from the callback, not stop the loop
  }
  console.log(num);
});
// Output: 1, 2, 3
```

### Best Practices & Use Cases for `forEach`

1. **Side Effects**: `forEach` is great for operations that affect something outside the array, such as updating the UI, logging values, or interacting with APIs.

2. **Avoid Mutations**: If you're tempted to modify the array in a `forEach`, consider using methods like `map` (for returning a transformed array) or `reduce` (for accumulating results).

3. **Performance Considerations**: Since `forEach` does not provide early exit or performance optimization controls (like `break` in a `for` loop), it can be less efficient for large arrays if you need to conditionally exit or manage performance.

### Summary of Looping Options

- **`for` loop**: High control, flexible for all cases, allows `break`, `continue`, and `return`.
- **`forEach`**: Simpler, but no early exit and often used for side effects or readability.
- **`for...of`**: Cleaner syntax than `for` for iterating over values in arrays, supports `break` and `return`.
- **`while` loop**: Useful when the number of iterations is not predefined, supports `break`.
- **`do-while` loop**: Similar to `while`, but ensures at least one execution.

### 4. Practical Use Case

Consider a web application where users can filter products by categories. You might use a `for` loop to iterate over a list of products and an `if` condition to check which category each product belongs to before displaying it:

```typescript
function filterProductsByCategory(
  products: Product[],
  category: string
): Product[] {
  const filteredProducts: Product[] = [];
  for (const product of products) {
    if (product.category === category) {
      filteredProducts.push(product);
    }
  }
  return filteredProducts;
}
```

### 5. Common Mistakes & Best Practices

1. **Avoid Infinite Loops**: Always ensure that the loop condition will eventually become false. This is especially tricky with `while` and `do-while` loops.
2. **Use `for...of` for Iterating Arrays**: It's easier and safer than `for` loops when you don’t need the index.

3. **Performance Considerations**:
   - Use `for` loops when performance is critical, especially in large arrays. It's generally the fastest, followed by `for...of`.
   - `break` can be used to exit any loop early for optimization, whereas `return` exits both the loop and the function.

### 6. Comparison of Loops

- **for loop**: Most flexible and typically faster for performance-critical tasks.
- **while loop**: Useful when the number of iterations isn't known ahead of time.
- **do-while loop**: Ensures that the loop runs at least once.
- **for...of loop**: Cleaner syntax for arrays and iterable objects but slightly slower than `for`.

**Break**: All loop types support `break` to terminate the loop early.  
**Return**: It exits the entire function, making it useful when you want to stop processing entirely.
