# Phase 2: Problem-Solving & Data Structures (4-6 Weeks)

## Week 1-2: Data Structures Fundamentals

### Objectives:

- Master essential data structures like arrays, linked lists, stacks, queues, hash tables, maps, and sets.
- Develop a foundational understanding of recursion and its applications in problem-solving.

### Study Topics:

#### 2.1. **Arrays & Linked Lists:**

- Arrays: Dynamic resizing, accessing elements, and common operations.
- Linked Lists: Node structure, singly vs. doubly linked lists, typical operations (insert, delete, search).

#### 2.2. **Stacks & Queues:**

- Stacks: LIFO (Last In, First Out), common uses (e.g., backtracking algorithms).
- Queues: FIFO (First In, First Out), task scheduling, and circular queues.

#### 2.3. **Hash Tables & Maps:**

- Hash Tables: Hashing concepts, collision resolution (chaining, open addressing).
- Maps: Differences between `Map` and `Object`, maintaining insertion order, key types, and performance.

#### 2.4. **Sets:**

- Unique value storage, operations, and differences from arrays.

#### 2.5. **Recursion Basics:**

- Understanding recursion: base case and recursive case.
- Examples: factorials, Fibonacci sequence, and tree traversal (pre-order, in-order, post-order).

#### 2.6. **Graphs:**

### Exercises:

- Implement linked lists, stacks, queues, and hash tables in TypeScript.
- Demonstrate `Map` advantages over `Object` for search, add, and delete operations.
- Write recursive functions for factorials, Fibonacci sequence, and tree traversals.

### Challenges:

- Build a **Data Structure Library** in TypeScript including stacks, queues, linked lists, hash tables, `Map`, and `Set`.
- Develop a **URL Shortener** using `Map` for quick lookups.
- Solve recursion-based problems like calculating permutations and implementing recursive tree traversal.

## Week 3-4: Advanced Algorithms, Recursion & Optimization

### Objectives:

- Understand advanced searching, sorting, and dynamic programming techniques.
- Master recursive approaches and memoization for optimized solutions.

### Study Topics:

#### 2.7. **Searching Algorithms:**

- Linear Search, Binary Search, DFS, and BFS.

#### 2.8. **Sorting Algorithms:**

- Quick Sort, Merge Sort, and Heap Sort.

#### 2.9.. **Dynamic Programming with Recursion:**

- Memoization and tabulation in dynamic programming.
- Optimizing recursive solutions using memoization (e.g., Fibonacci sequence, knapsack problem).

### Exercises:

- Implement binary search, analyze its efficiency, and write Quick Sort.
- Practice dynamic programming with recursive solutions for classic problems like the Fibonacci sequence.

### Challenges:

- Solve complex recursion problems on platforms like LeetCode or CodeWars.
- Build a **Dynamic Programming Library** in TypeScript with recursive solutions for problems like the longest common subsequence.

### Objectives:
