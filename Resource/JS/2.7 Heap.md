## Heap in TypeScript

### 1. Core Concept and Significance

A **Heap** is a specialized binary tree-based data structure that satisfies the **heap property**:

- In a **Max-Heap**, the value of each parent node is greater than or equal to the values of its children, making the largest element always at the root.
- In a **Min-Heap**, the value of each parent node is less than or equal to the values of its children, making the smallest element always at the root.

**Heaps** are primarily used to implement **priority queues** and are useful in sorting algorithms such as **Heap Sort**. They offer efficient access to the minimum or maximum element, making insertion and deletion operations logarithmic in complexity.

### 2. Code Examples with JSDoc and Explanation

TypeScript does not have built-in support for heaps, but they can be implemented using arrays.

#### Implementation of a Min-Heap

```typescript
/**
 * Class representing a Min-Heap data structure.
 */
class MinHeap {
  private heap: number[];

  constructor() {
    this.heap = [];
  }

  /**
   * Inserts a new value into the heap.
   * @param {number} value - The value to insert.
   */
  insert(value: number): void {
    this.heap.push(value);
    this.bubbleUp();
  }

  /**
   * Removes and returns the minimum value from the heap.
   * @returns {number | undefined} The minimum value or undefined if the heap is empty.
   */
  extractMin(): number | undefined {
    if (this.heap.length === 0) return undefined;
    const min = this.heap[0];
    const last = this.heap.pop();
    if (this.heap.length > 0 && last !== undefined) {
      this.heap[0] = last;
      this.bubbleDown();
    }
    return min;
  }

  /**
   * Moves the last element up to restore the heap property.
   * @private
   */
  private bubbleUp(): void {
    let index = this.heap.length - 1;
    const element = this.heap[index];

    while (index > 0) {
      const parentIndex = Math.floor((index - 1) / 2);
      const parent = this.heap[parentIndex];

      if (element >= parent) break;

      this.heap[index] = parent;
      index = parentIndex;
    }
    this.heap[index] = element;
  }

  /**
   * Moves the root element down to restore the heap property.
   * @private
   */
  private bubbleDown(): void {
    let index = 0;
    const length = this.heap.length;
    const element = this.heap[0];

    while (true) {
      let leftChildIndex = 2 * index + 1;
      let rightChildIndex = 2 * index + 2;
      let swap = null;

      if (leftChildIndex < length) {
        const leftChild = this.heap[leftChildIndex];
        if (leftChild < element) swap = leftChildIndex;
      }

      if (rightChildIndex < length) {
        const rightChild = this.heap[rightChildIndex];
        if (
          (swap === null && rightChild < element) ||
          (swap !== null && rightChild < this.heap[swap])
        ) {
          swap = rightChildIndex;
        }
      }

      if (swap === null) break;

      this.heap[index] = this.heap[swap];
      index = swap;
    }
    this.heap[index] = element;
  }
}

// Usage
const minHeap = new MinHeap();
minHeap.insert(3);
minHeap.insert(1);
minHeap.insert(6);
minHeap.insert(5);
minHeap.insert(2);

console.log(minHeap.extractMin()); // Output: 1
console.log(minHeap.extractMin()); // Output: 2
```

#### Explanation:

- **`insert(value)`**: Adds a new element to the heap and adjusts the position of elements to maintain the min-heap property using the `bubbleUp()` helper function.
- **`extractMin()`**: Removes and returns the smallest element (root). Then, it uses `bubbleDown()` to restore the heap property.
- **`bubbleUp()`**: Moves the recently added element up until the heap property is satisfied.
- **`bubbleDown()`**: Moves the root element down until the heap property is restored.

### 3. Practical Use Case

#### Use Case: Priority Queue

A common application of a heap is a **priority queue** where elements are processed based on their priority. A min-heap or max-heap is often used to efficiently retrieve and remove the highest (or lowest) priority element.

### 4. Common Mistakes and Best Practices

#### Common Mistakes:

- **Not Maintaining Heap Property**: Forgetting to call `bubbleUp()` after insertion or `bubbleDown()` after extraction can lead to an unsorted heap, breaking the heap property.
- **Improper Index Calculation**: Inserting or removing nodes without correctly calculating the child or parent indices can disrupt the heap structure.

#### Best Practices:

- **Use Type Constraints**: When implementing generic heaps, ensure type constraints are defined to handle only comparable types.
- **Encapsulation**: Keep the helper functions (`bubbleUp` and `bubbleDown`) private to ensure that only class methods can alter the heap structure directly.
- **Leverage TypeScript’s `Array` Methods**: While implementing heaps, use built-in `Array` methods like `push` and `pop` to simplify operations.
