# Graphs in TypeScript

## 1. Core Concept and Significance

A **Graph** is a data structure composed of nodes (also called vertices) and edges. Each edge connects two nodes and represents a relationship between them. Graphs can be classified as:

- **Directed or Undirected**: In directed graphs, edges have a direction, indicating the flow from one node to another. In undirected graphs, edges have no direction.
- **Weighted or Unweighted**: In weighted graphs, edges have an associated weight, often representing costs, distances, or other measures. Unweighted graphs lack this property.

Graphs are significant due to their versatility in representing relationships and connections, making them essential for applications like social networks, search engines, and mapping systems.

## 2. Code Examples in TypeScript

TypeScript does not have built-in support specifically for graphs, but you can implement graph structures using classes and interfaces.

### Example: Implementing a Graph with Adjacency List

```typescript
// Define a type alias for a graph
type GraphNode = string;

// Define the Graph class with generics
class Graph<T extends GraphNode> {
  private adjacencyList: Map<T, T[]>;

  constructor() {
    this.adjacencyList = new Map();
  }

  // Add a node to the graph
  addNode(node: T): void {
    if (!this.adjacencyList.has(node)) {
      this.adjacencyList.set(node, []);
    }
  }

  // Add an edge between two nodes
  addEdge(source: T, destination: T): void {
    this.adjacencyList.get(source)?.push(destination);
    this.adjacencyList.get(destination)?.push(source); // For undirected graphs
  }

  // Get all nodes connected to a given node
  getNeighbors(node: T): T[] | undefined {
    return this.adjacencyList.get(node);
  }

  // Print the graph
  printGraph(): void {
    for (let [node, neighbors] of this.adjacencyList) {
      console.log(`${node} -> ${neighbors.join(', ')}`);
    }
  }
}

// Usage
const graph = new Graph<string>();

// Adding nodes
graph.addNode('A');
graph.addNode('B');
graph.addNode('C');

// Adding edges
graph.addEdge('A', 'B');
graph.addEdge('A', 'C');

// Printing the graph
graph.printGraph();
// Output:
// A -> B, C
// B -> A
// C -> A
```

### Explanation:

- The `Graph` class uses an **adjacency list** represented as a `Map` to store nodes and their connections.
- The `addNode` method ensures that each node has an entry in the adjacency list.
- The `addEdge` method adds an edge between two nodes. For an undirected graph, the connection is added in both directions.
- The `printGraph` method iterates over the adjacency list and displays the graph’s connections.

In this example, the `DirectedGraph` class adds directed edges. Unlike an undirected graph, it only adds an edge in one direction (`source -> destination`).

### Implementing a Weighted Graph

```typescript
class WeightedGraph<T> {
  private adjacencyList: Map<T, Map<T, number>>;

  constructor() {
    this.adjacencyList = new Map();
  }

  addNode(node: T): void {
    if (!this.adjacencyList.has(node)) {
      this.adjacencyList.set(node, new Map());
    }
  }

  addEdge(source: T, destination: T, weight: number): void {
    if (
      !this.adjacencyList.has(source) ||
      !this.adjacencyList.has(destination)
    ) {
      throw new Error('Source or destination node does not exist.');
    }
    this.adjacencyList.get(source)?.set(destination, weight);
  }

  getNeighbors(node: T): Map<T, number> | undefined {
    return this.adjacencyList.get(node);
  }

  printGraph(): void {
    for (let [node, neighbors] of this.adjacencyList) {
      const edges = Array.from(neighbors.entries())
        .map(([dest, weight]) => `${dest} (${weight})`)
        .join(', ');
      console.log(`${node} -> ${edges}`);
    }
  }
}

// Example usage
const weightedGraph = new WeightedGraph<string>();

weightedGraph.addNode('A');
weightedGraph.addNode('B');
weightedGraph.addNode('C');

weightedGraph.addEdge('A', 'B', 5);
weightedGraph.addEdge('A', 'C', 3);
weightedGraph.addEdge('B', 'C', 2);

weightedGraph.printGraph();
// Output:
// A -> B (5), C (3)
// B -> C (2)
// C ->
```

In this `WeightedGraph` example, edges between nodes also carry a `weight`. This is implemented using a nested `Map` structure where each node maps to another map, indicating its connections and the associated weights.

## 3. Practical Use Case

### Use Case: Social Network Connections

Graphs are ideal for modeling social networks, where nodes represent users, and edges represent friendships or follows. By implementing a graph structure, you can:

- **Find connections**: Use depth-first or breadth-first search to find mutual friends or connections.
- **Suggest friends**: Identify nodes with common connections that aren’t directly connected.

For example, in a social network application, a graph could be used to find all users connected to a particular user up to a certain degree, helping in friend suggestions.

- **Weighted graphs** are used in network routing, where nodes represent devices, and weights represent transmission costs.

- **Directed graphs** are beneficial in scenarios like web crawlers, where a page (node) has links (directed edges) to other pages.

## 4. Common Mistakes and Best Practices

### Common Mistakes

1. **Forgetting Edge Cases**: When managing graphs, especially directed or weighted ones, be mindful of disconnected nodes, self-loops, and bidirectional edges.
2. **Inefficient Traversal**: Graph traversal algorithms can be costly if implemented incorrectly. Ensure you use efficient traversal techniques (like DFS or BFS) with proper checks to avoid unnecessary computations.

### Best Practices

1. **Choose the Right Graph Representation**: Depending on the application, choose between adjacency lists (efficient for sparse graphs) and adjacency matrices (suitable for dense graphs).
2. **Manage Cycles Carefully**: When working with directed graphs, cycles can complicate traversal and search operations. Use cycle detection algorithms if cycles can be problematic.
3. **Use TypeScript Generics**: Generics allow you to define graphs that can work with any node type, making the code more flexible and reusable.
4. **Choose the Right Data Structure**: Use an adjacency matrix for dense graphs or an adjacency list for sparse graphs.
5. **Leverage TypeScript’s Type Safety**: Use generics to ensure your graph can handle various types while retaining type safety.
