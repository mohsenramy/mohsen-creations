# Stacks & Queues in TypeScript

## 1. Core Concept and Significance

Stacks and Queues are fundamental data structures used to store and retrieve data. They differ in the order of how data is accessed and removed:

- Stacks follow a Last In, First Out (LIFO) approach. The last element added is the first one to be removed. Stacks are commonly used for undo mechanisms, backtracking, and recursion.
- Queues follow a First In, First Out (FIFO) approach. The first element added is the first one to be removed. Queues are useful for scheduling tasks, handling asynchronous events, and breadth-first search algorithms.

These data structures are not directly built into TypeScript, but they can be easily implemented using arrays and classes.

## 2. Code Examples

### Example 1: Stack Implementation

```typescript
// Stack class using LIFO principle
class Stack<T> {
  private items: T[] = [];

  // Adds an element to the top of the stack
  push(item: T): void {
    this.items.push(item);
  }

  // Removes and returns the top element from the stack
  pop(): T | undefined {
    return this.items.pop();
  }

  // Returns the top element without removing it
  peek(): T | undefined {
    return this.items[this.items.length - 1];
  }

  // Checks if the stack is empty
  isEmpty(): boolean {
    return this.items.length === 0;
  }

  // Returns the number of elements in the stack
  size(): number {
    return this.items.length;
  }
}

// Usage
const stack = new Stack<number>();
stack.push(1);
stack.push(2);
console.log(stack.peek()); // Output: 2
console.log(stack.pop()); // Output: 2
console.log(stack.size()); // Output: 1
```

### Example 2: Queue Implementation

```typescript
// Queue class using FIFO principle
class Queue<T> {
  private items: T[] = [];

  // Adds an element to the end of the queue
  enqueue(item: T): void {
    this.items.push(item);
  }

  // Removes and returns the first element from the queue
  dequeue(): T | undefined {
    return this.items.shift();
  }

  // Returns the first element without removing it
  front(): T | undefined {
    return this.items[0];
  }

  // Checks if the queue is empty
  isEmpty(): boolean {
    return this.items.length === 0;
  }

  // Returns the number of elements in the queue
  size(): number {
    return this.items.length;
  }
}

// Usage
const queue = new Queue<string>();
queue.enqueue('A');
queue.enqueue('B');
console.log(queue.front()); // Output: "A"
console.log(queue.dequeue()); // Output: "A"
console.log(queue.size()); // Output: 1
```

### Example 3: Circular Queue Implementation

A circular queue is a fixed-size queue that wraps around when it reaches the end of the array, efficiently reusing space. Circular queues are useful when you need to maintain a constant amount of storage but still need the flexibility of a queue.

```typescript
class CircularQueue<T> {
  private items: (T | null)[];
  private front: number;
  private rear: number;
  private size: number;
  private capacity: number;

  constructor(capacity: number) {
    this.capacity = capacity;
    this.items = new Array<T | null>(capacity).fill(null);
    this.front = -1;
    this.rear = -1;
    this.size = 0;
  }

  // Adds an element to the rear of the circular queue
  enqueue(item: T): boolean {
    if (this.isFull()) {
      console.log('Queue is full');
      return false;
    }
    if (this.front === -1) this.front = 0; // Initialize front pointer

    this.rear = (this.rear + 1) % this.capacity;
    this.items[this.rear] = item;
    this.size++;
    return true;
  }

  // Removes and returns the front element of the circular queue
  dequeue(): T | null {
    if (this.isEmpty()) {
      console.log('Queue is empty');
      return null;
    }

    const item = this.items[this.front];
    this.items[this.front] = null;
    if (this.front === this.rear) {
      // Reset queue when last element is removed
      this.front = -1;
      this.rear = -1;
    } else {
      this.front = (this.front + 1) % this.capacity;
    }
    this.size--;
    return item;
  }

  // Returns the front element without removing it
  peek(): T | null {
    if (this.isEmpty()) {
      console.log('Queue is empty');
      return null;
    }
    return this.items[this.front];
  }

  // Checks if the queue is empty
  isEmpty(): boolean {
    return this.size === 0;
  }

  // Checks if the queue is full
  isFull(): boolean {
    return this.size === this.capacity;
  }

  // Returns the current size of the queue
  getSize(): number {
    return this.size;
  }
}

// Usage example
const circularQueue = new CircularQueue<number>(3);
circularQueue.enqueue(1);
circularQueue.enqueue(2);
circularQueue.enqueue(3);
console.log(circularQueue.isFull()); // Output: true

console.log(circularQueue.dequeue()); // Output: 1
circularQueue.enqueue(4);
console.log(circularQueue.peek()); // Output: 2

circularQueue.enqueue(5); // Output: Queue is full
```

Explanation

1. Enqueue Operation:
   - First, it checks if the queue is full. If it is, it exits without adding the element.
   - If the queue is empty initially, it sets the front pointer to 0.
   - It calculates the new position for the rear pointer using (this.rear + 1) % this.capacity to wrap around if needed.
   - It then inserts the element at the rear position.
2. Dequeue Operation:
   - It first checks if the queue is empty. If it is, it exits without removing any element.
   - It stores and removes the item at the front position.
   - If the item removed is the last element, it resets front and rear to -1.
   - Otherwise, it updates front to (this.front + 1) % this.capacity.
3. Peek Operation:
   - It simply returns the element at the front without modifying the queue.

## 3. Practical Use Cases

### Stack Use Case: Backtracking in Algorithms

Stacks are commonly used in algorithms that involve backtracking, such as solving mazes or performing depth-first searches (DFS). The LIFO nature of stacks helps track the most recent path or decision, allowing the algorithm to backtrack when it hits a dead end.

### Queue Use Case: Task Scheduling

Queues are ideal for task scheduling, where tasks need to be processed in the order they arrive. For example, an operating system’s task scheduler uses queues to manage processes that need CPU time. Queues are also used in breadth-first searches (BFS), where they help manage nodes that need to be explored in layers.

### Circular Queue Use Case:

- Fixed Memory Scheduling: In systems that need to process data in a strict order and maintain a fixed memory footprint, like scheduling tasks in an operating system.
- Streaming Data Processing: Circular queues are often used in buffering scenarios where continuous data streams (like audio or video) need to be processed without growing the memory size.

## 4. Common Mistakes and Best Practices

### Common Mistakes

- **Using the Wrong Data Structure:** Choosing between a stack and a queue is crucial; ensure you select the one that matches the order of processing your application needs.
- **Not Handling Edge Cases**: When implementing stacks and queues, remember to handle cases where you try to pop from an empty stack or dequeue from an empty queue.

### Best Practices

- **Use Arrays for Simple Implementations**: In TypeScript, stacks and queues can be easily implemented with arrays, which support push, pop, shift, and unshift operations.
- **Encapsulate Behavior in Classes**: To improve maintainability and readability, encapsulate stack and queue behavior within classes.
- **Consider Circular Queues for Fixed-Size Queues**: For scenarios where memory efficiency is critical, consider using a circular queue, which utilizes a fixed-size array and reuses space by wrapping around.
