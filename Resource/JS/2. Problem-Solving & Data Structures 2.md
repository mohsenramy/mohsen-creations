# Phase 2: Problem-Solving & Data Structures (4-6 Weeks)

## Week 1-2: Data Structures Fundamentals

### Objectives:
- Master essential data structures like arrays, linked lists, stacks, queues, hash tables, maps, sets, trees, graphs, and heaps.
- Develop a foundational understanding of recursion and its applications in problem-solving.

### Study Topics:

#### 2.1. **Arrays & Linked Lists:**
- Arrays: Dynamic resizing, accessing elements, and common operations.
- Linked Lists: Node structure, singly vs. doubly linked lists, typical operations (insert, delete, search).

#### 2.2. **Stacks & Queues:**
- Stacks: LIFO (Last In, First Out), common uses (e.g., backtracking algorithms).
- Queues: FIFO (First In, First Out), task scheduling, and circular queues.

#### 2.3. **Hash Tables & Maps:**
- Hash Tables: Hashing concepts, collision resolution (chaining, open addressing).
- Maps: Differences between `Map` and `Object`, maintaining insertion order, key types, and performance.

#### 2.4. **Sets:**
- Unique value storage, operations, and differences from arrays.

#### 2.5. **Recursion Basics:**
- Understanding recursion: base case and recursive case.
- Examples: factorials, Fibonacci sequence, and tree traversal (pre-order, in-order, post-order).

#### 2.6. **Trees:**
- Tree basics: Terminology (root, node, leaf, parent, child), hierarchical structure.
- Binary Trees: Traversal techniques (pre-order, in-order, post-order), insertion, deletion, and searching.
- Binary Search Trees (BST): Ordered trees, searching, insertion, and deletion.
- Balanced Trees: AVL Trees, Red-Black Trees, maintaining balance with rotations.
- Applications of Trees: Decision trees, expression trees, and parsing hierarchical data.

#### 2.7. **Graphs:**
- Graph Basics: Terminology (vertices, edges), directed vs. undirected graphs.
- Graph Representation: Adjacency list vs. adjacency matrix.
- Graph Traversal: Depth-First Search (DFS), Breadth-First Search (BFS).
- Graph Types: Weighted graphs, unweighted graphs, cyclic and acyclic graphs.
- Shortest Path Algorithms: Dijkstra’s Algorithm, Bellman-Ford, Floyd-Warshall.

#### 2.8. **Heaps:**
- Heap Basics: Min-heap and max-heap properties.
- Binary Heaps: Priority queues, heapify operations, insertion and deletion.
- Heap Applications: Sorting (Heapsort), finding k-largest or k-smallest elements.

### Exercises:
- Implement linked lists, stacks, queues, hash tables, and binary search trees in TypeScript.
- Write recursive functions for tree traversal (pre-order, in-order, post-order).
- Implement graph traversal (DFS, BFS) and basic operations.
- Build a heap and practice insertion, deletion, and heapify operations.

### Challenges:
- Build a **Binary Search Tree Library** with core operations (insert, search, delete).
- Solve tree-based problems (e.g., finding the depth of a tree, checking for balanced trees).
- Implement a **Priority Queue** using heaps and solve problems like finding the k-largest elements.

## Week 3-4: Advanced Algorithms, Recursion & Optimization

### Objectives:
- Understand advanced searching, sorting, and dynamic programming techniques.
- Master recursive approaches and memoization for optimized solutions.

### Study Topics:

#### 2.9. **Searching Algorithms:**
- Linear Search, Binary Search, Depth-First Search (DFS), and Breadth-First Search (BFS).

#### 2.10. **Sorting Algorithms:**
- Quick Sort, Merge Sort, and Heap Sort.

#### 2.11. **Advanced Tree Algorithms:**
- Tree Traversal Algorithms: DFS, BFS in trees.
- Binary Search Tree Optimizations: Self-balancing trees (AVL, Red-Black Trees).
- Segment Trees & Fenwick Trees: Range queries and updates.

#### 2.12. **Graph Algorithms:**
- Graph Traversal Revisited: DFS, BFS, and cycle detection.
- Shortest Path Algorithms: Implementing Dijkstra’s and Bellman-Ford algorithms.
- Graph Connectivity: Connected components, strongly connected components.
- Topological Sorting: Sorting in Directed Acyclic Graphs (DAGs).

#### 2.13. **Heap Algorithms:**
- Heapsort: Sorting using heaps.
- Priority Queue: Implementing priority queues with heaps.
- Heap Applications: Solving problems like finding the median of a stream or k-largest elements.

#### 2.14. **Dynamic Programming with Recursion:**
- Memoization and tabulation in dynamic programming.
- Optimizing recursive solutions (e.g., Fibonacci sequence, knapsack problem).

### Exercises:
- Implement binary search, graph traversal (DFS, BFS), and Dijkstra’s algorithm.
- Write and optimize recursive functions using dynamic programming techniques.
- Practice heapsort and implement heap-based priority queues.

### Challenges:
- Build a **Dynamic Programming Library** in TypeScript.
- Solve tree-based problems like finding the lowest common ancestor.
- Develop efficient solutions for graph algorithms (e.g., shortest path, cycle detection).
