## System Design Fundamentals

### 1. Core Concept and Significance

System design refers to the process of defining the architecture, components, modules, interfaces, and data for a system to satisfy specified requirements. It is significant because it helps create systems that are scalable, maintainable, and resilient. Understanding system design fundamentals is crucial for building applications that can handle growing user demand and adapt to changes without requiring complete rewrites.

### 2. Code Examples

#### Designing Scalable Systems

Scalability is the capability of a system to handle a growing amount of work or its potential to accommodate growth. It can be achieved through:

- **Horizontal Scaling**: Adding more machines or instances.
- **Vertical Scaling**: Adding more power (CPU, RAM) to existing machines.
- **Load Balancing**: Distributing incoming network traffic across multiple servers.

Here’s a simplified example of a load balancer in JavaScript:

```javascript
/**
 * Simple load balancer to distribute requests among servers
 * @param {Array<string>} servers - List of server URLs
 * @returns {Function} - A function to route requests
 */
function createLoadBalancer(servers) {
  let index = 0; // Track the current server index

  return function routeRequest() {
    // Get the current server URL
    const server = servers[index];
    // Update index for round-robin routing
    index = (index + 1) % servers.length;
    return server; // Return the server to handle the request
  };
}

// Usage
const servers = [
  'http://server1.com',
  'http://server2.com',
  'http://server3.com',
];
const loadBalancer = createLoadBalancer(servers);

// Simulating requests
for (let i = 0; i < 10; i++) {
  console.log(`Request routed to: ${loadBalancer()}`);
}
```

### Explanation

- **createLoadBalancer**: A function that initializes a load balancer.
- **servers**: An array of server URLs.
- **routeRequest**: A nested function that routes requests to servers in a round-robin fashion.

### TypeScript Built-in Support

TypeScript allows you to define strict types for your system design components, improving the reliability of your system. For example, using interfaces and generics can help ensure that your data structures are used correctly.

```typescript
interface Server {
  url: string;
}

/**
 * Simple load balancer to distribute requests among servers
 * @param {Array<Server>} servers - List of server objects
 * @returns {Function} - A function to route requests
 */
function createLoadBalancer(servers: Server[]) {
  let index = 0;

  return function routeRequest(): string {
    const server = servers[index];
    index = (index + 1) % servers.length;
    return server.url;
  };
}

// Usage
const servers: Server[] = [
  { url: 'http://server1.com' },
  { url: 'http://server2.com' },
];
const loadBalancer = createLoadBalancer(servers);
```

### 3. Practical Use Case

**E-commerce Application**: In an e-commerce platform, you may expect spikes in traffic during sales events. Implementing a load balancer allows you to distribute user requests among multiple server instances, ensuring that no single server becomes a bottleneck. By scaling horizontally, you can easily add more servers to accommodate increased traffic without affecting the performance of the application.

### 4. Common Mistakes and Best Practices

- **Not Planning for Scalability**: Many developers overlook the need for scalability during the initial design phase. Always consider future growth and design systems that can scale easily.
- **Ignoring Load Balancing**: Not implementing a load balancer can lead to uneven traffic distribution and server overloads.
- **Choosing the Wrong Scaling Strategy**: Depending on the application, horizontal scaling may be more beneficial than vertical scaling or vice versa. Evaluate the needs of your application carefully.
- **Lack of Monitoring and Alerts**: Implementing monitoring tools can help you detect issues early and adjust your scaling strategy accordingly.

### Database Scaling

When dealing with databases, scaling can involve techniques like sharding (partitioning data across multiple databases) and replication (duplicating data across multiple databases to ensure availability).

**Sharding Example in TypeScript:**

```typescript
/**
 * Function to retrieve user data based on user ID with sharding
 * @param {string} userId - The ID of the user to fetch
 * @param {Array<string>} shards - List of database shard URLs
 * @returns {Promise<string>} - The user data
 */
async function getUserData(userId: string, shards: string[]): Promise<string> {
  const shardIndex = parseInt(userId) % shards.length; // Determine shard based on user ID
  const shard = shards[shardIndex];
  // Simulate fetching user data from the selected shard
  return `Fetched data for user ${userId} from ${shard}`;
}

// Usage
const shards = ['db-shard1.com', 'db-shard2.com'];
getUserData('12345', shards).then((data) => console.log(data));
```

### Caching Strategies

Using caching strategies such as Redis or Memcached can drastically improve the performance of your application by reducing the load on your database and speeding up response times.

**Example of Using Redis for Caching:**

```typescript
import Redis from 'ioredis';

/**
 * Class to manage caching with Redis
 */
class CacheManager {
  private redis: Redis.Redis;

  constructor() {
    this.redis = new Redis(); // Initialize Redis client
  }

  /**
   * Set cache value
   * @param {string} key - The cache key
   * @param {string} value - The value to cache
   * @param {number} ttl - Time to live in seconds
   */
  async setCache(key: string, value: string, ttl: number): Promise<void> {
    await this.redis.set(key, value, 'EX', ttl); // Set cache with expiration
  }

  /**
   * Get cache value
   * @param {string} key - The cache key
   * @returns {Promise<string | null>} - The cached value or null if not found
   */
  async getCache(key: string): Promise<string | null> {
    return await this.redis.get(key); // Retrieve cached value
  }
}

// Usage
const cacheManager = new CacheManager();
cacheManager.setCache('user:1', JSON.stringify({ name: 'John' }), 3600);
cacheManager.getCache('user:1').then((data) => console.log(data));
```

### Content Delivery Networks (CDNs)

CDNs are crucial for delivering static content (like images, scripts, and styles) efficiently to users around the globe. By caching content closer to users, CDNs reduce latency and improve load times.
