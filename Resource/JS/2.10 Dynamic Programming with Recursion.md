### Dynamic Programming with Recursion in TypeScript

Dynamic programming (DP) is a problem-solving technique that solves complex problems by breaking them down into simpler subproblems. The core idea is to solve each subproblem only once and store the result, usually using memoization or tabulation, which optimizes recursive algorithms by reducing redundant calculations. This approach is particularly useful in scenarios where a solution can be derived from solutions to smaller instances of the same problem, making it efficient and highly relevant in optimization problems like Fibonacci sequence calculations, knapsack problem, and many others.

## 1. Core Concepts

### Memoization

Memoization is a top-down approach to dynamic programming where results of expensive function calls are stored for future use. This helps avoid redundant calculations, thereby optimizing recursive solutions.

### Tabulation

Tabulation is a bottom-up approach where solutions to all subproblems are systematically built up in a table, ensuring each subproblem is solved once.

## 2. Code Example: Fibonacci Sequence with Memoization

Here's an example of the Fibonacci sequence, optimized using recursion and memoization. TypeScript's static typing ensures that only valid types are used, enhancing code reliability.

```typescript
/**
 * Calculates the nth Fibonacci number using recursion and memoization.
 * @param {number} n - The position in the Fibonacci sequence.
 * @param {Map<number, number>} memo - A map to store previously calculated results.
 * @returns {number} - The Fibonacci number at position n.
 */
function fibonacci(n: number, memo: Map<number, number> = new Map()): number {
  if (n <= 1) return n;
  if (memo.has(n)) return memo.get(n)!; // Fetch from memo if available

  // Recursively calculate and store result in memo
  const result = fibonacci(n - 1, memo) + fibonacci(n - 2, memo);
  memo.set(n, result);
  return result;
}

console.log(fibonacci(10)); // Output: 55
```

### Explanation

- **Memoization**: We use a `Map` to store previously computed Fibonacci values, reducing redundant calculations.
- **Recursion**: The function calls itself until it reaches the base cases, `fibonacci(0)` or `fibonacci(1)`, which are well-defined as `0` and `1`, respectively.

## 4. Practical Use Case:

### Knapsack Problem with Memoization

The knapsack problem is another example where dynamic programming can be used to optimize recursive solutions. Here’s a TypeScript example using memoization:

```typescript
/**
 * Solves the Knapsack problem using recursion and memoization.
 * @param {number[]} weights - Array of item weights.
 * @param {number[]} values - Array of item values corresponding to weights.
 * @param {number} capacity - Total capacity of the knapsack.
 * @param {number} n - Number of items.
 * @param {Map<string, number>} memo - Memoization map to store previously calculated results.
 * @returns {number} - Maximum value that fits within the knapsack capacity.
 */
function knapsack(
  weights: number[],
  values: number[],
  capacity: number,
  n: number,
  memo: Map<string, number> = new Map()
): number {
  if (n === 0 || capacity === 0) return 0;

  const key = `${n}-${capacity}`;
  if (memo.has(key)) return memo.get(key)!;

  // If weight of nth item is more than knapsack capacity, exclude it
  if (weights[n - 1] > capacity) {
    const result = knapsack(weights, values, capacity, n - 1, memo);
    memo.set(key, result);
    return result;
  } else {
    // Calculate max of including or excluding the nth item
    const include =
      values[n - 1] +
      knapsack(weights, values, capacity - weights[n - 1], n - 1, memo);
    const exclude = knapsack(weights, values, capacity, n - 1, memo);
    const result = Math.max(include, exclude);
    memo.set(key, result);
    return result;
  }
}

const weights = [1, 3, 4, 5];
const values = [1, 4, 5, 7];
const capacity = 7;
console.log(knapsack(weights, values, capacity, weights.length)); // Output: 9
```

### 0/1 Knapsack Problem with Tabular

```typescript
/**
 * Solves the 0/1 Knapsack problem using dynamic programming.
 * @param weights - Array of item weights.
 * @param values - Array of item values.
 * @param capacity - Maximum capacity of the knapsack.
 * @returns The maximum value that can be obtained within the given capacity.
 */
function knapsack(
  weights: number[],
  values: number[],
  capacity: number
): number {
  const n = weights.length;
  const dp: number[][] = Array(n + 1)
    .fill(0)
    .map(() => Array(capacity + 1).fill(0));

  // Build table dp[][] in a bottom-up manner
  for (let i = 1; i <= n; i++) {
    for (let w = 0; w <= capacity; w++) {
      if (weights[i - 1] <= w) {
        // Option 1: Exclude the item
        // Option 2: Include the item and add its value
        dp[i][w] = Math.max(
          dp[i - 1][w],
          dp[i - 1][w - weights[i - 1]] + values[i - 1]
        );
      } else {
        // Cannot include the item as it exceeds the current weight limit
        dp[i][w] = dp[i - 1][w];
      }
    }
  }

  // The bottom-right corner contains the maximum value for the given capacity
  return dp[n][capacity];
}

// Example usage:
const weights = [2, 3, 4];
const values = [3, 4, 5];
const capacity = 5;

const maxValue = knapsack(weights, values, capacity);
console.log(`Maximum value achievable: ${maxValue}`);
```

### Explanation of the Code

1. **Initialize DP Table**: A 2D array `dp` is created where `dp[i][w]` holds the maximum value achievable with the first `i` items and capacity `w`.
2. **Populate DP Table**:
   - **Loop Over Items and Capacities**: The outer loop goes through each item, and the inner loop iterates over capacities from `0` up to the knapsack’s capacity.
   - **Check Item Fit**: For each item and capacity, we check if the item can fit (i.e., its weight is less than or equal to the current capacity).
     - If it can, we take the maximum of:
       - The value without including the item (`dp[i - 1][w]`).
       - The value by including the item (`dp[i - 1][w - weights[i - 1]] + values[i - 1]`).
     - If it cannot fit, we carry over the value from the previous item (`dp[i - 1][w]`).
3. **Final Output**: The value at `dp[n][capacity]` holds the maximum value for the given capacity, considering all items.

### Practical Notes

- **Complexity**: The time complexity of this approach is \(O(n \times \text{capacity})\), where `n` is the number of items. This is generally efficient for moderate values of `n` and capacity.
- **Space Optimization**: Since each entry only depends on the previous row, you can reduce space to \(O(\text{capacity})\) by using a 1D array and updating it from the back.

This code provides an efficient, systematic way to solve the 0/1 Knapsack Problem, making it a good example of dynamic programming with tabulation.

### Explanation

- **Memoization with Map**: We store the computed results for combinations of `n` and `capacity` to avoid recalculating them.
- **Recursive Calls**: Each call considers two cases: including or excluding the current item, recursively evaluating each.

## 5. Common Mistakes and Best Practices

### Common Mistakes

1. **Not Using Memoization**: Without memoization, recursive solutions may become exponentially slow.
2. **Incorrect Key for Memoization**: When using multiple variables (like `n` and `capacity` in knapsack), failing to create a unique key can lead to incorrect results.

### Best Practices

- **Use Proper Data Structures**: Utilize `Map` for memoization due to its O(1) time complexity for retrieval and insertion.
- **Prefer Iterative Solutions Where Possible**: Iterative solutions (tabulation) can sometimes be more efficient than recursion due to call stack limitations.
- **Understand the Problem Constraints**: Ensure that dynamic programming is indeed needed; sometimes simpler greedy algorithms can suffice.
