# Phase 1: Advanced Core Concepts (4-6 Weeks)

## Week 1-2: Mastering Closures, Scopes, and Async Patterns

### Objectives:

- Gain deep understanding of closures and scopes.
- Master asynchronous programming, including Promises, async/await, and EventEmitters.

### Study Topics:

#### 1.1. **Closures & Scopes:**

- Closures allow functions to access variables from an enclosing scope even after the function has finished execution.
- Understanding the scope chain and how JavaScript searches for variables in nested scopes.

#### 1.2. **Async Patterns:**

- Learn callbacks, Promises, async/await, and the event loop.
- Understanding how the event loop handles asynchronous tasks.

### Exercises:

- Create a function that returns another function and utilizes closures to maintain private variables.
- Write a series of functions using callbacks and refactor them into Promises and async/await.

### Challenges:

- Build a small app that fetches data asynchronously from a public API and handles multiple API calls.

---

## Week 3-4: Functional Programming in JavaScript

### Objectives:

- Understand and apply functional programming concepts such as higher-order functions, immutability, and pure functions.

### Study Topics:

#### 1.3 **Higher-Order Functions:**

- Functions that take other functions as arguments or return them as results.
- Practice using `map()`, `reduce()`, and `filter()` in JavaScript.

#### 1.4 **Immutability & Pure Functions:**

- Refactor code to make it functional and avoid mutating data.

### Exercises:

- Create your own implementation of `map()`, `reduce()`, and `filter()`.
- Refactor code to ensure functions are pure and avoid side effects.

### Challenges:

- Build a small functional utility library in TypeScript that includes functions like deep copying, filtering, and merging data structures immutably.

---

> Week 5-6: Advanced TypeScript & Utility Types

### Objectives:

- Work with advanced TypeScript types, including generics, mapped types, and conditional types.

### Study Topics:

1. **Generics:**

   - Write functions and data structures that can work with any type while retaining type safety.

2. **Mapped & Conditional Types:**
   - Use mapped types to transform types and conditional types to build types based on conditions.

### Exercises:

- Implement a utility type that takes an object and makes all properties optional (`Partial<T>`).
- Write a function that takes an array of any type and returns the first element, while maintaining type inference.

### Challenges:

- Build a type-safe API client using TypeScript that accepts generics and infers API response shapes.

---

## Project: LRU Cache Library

### Description:

- Build an LRU (Least Recently Used) Cache as a reusable TypeScript library.

### Features:

- Store a fixed number of items and evict the least recently used ones when the limit is exceeded.
- Use TypeScript generics to allow any data type to be cached.
- Implement unit tests using **Jest**.

### Key Deliverables:

- A functional LRU Cache with efficient data storage and retrieval.
- Full unit test coverage using Jest.
- Refactor for performance improvements (e.g., using a doubly linked list for cache efficiency).
