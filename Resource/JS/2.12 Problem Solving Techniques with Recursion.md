# Problem-Solving Techniques with Recursion in TypeScript

## 1. Core Concept and Significance

Recursion is a programming technique where a function calls itself to solve a problem. It’s particularly useful for solving problems that can be broken down into smaller, similar subproblems. TypeScript supports recursion and also provides built-in type-checking, which helps ensure the recursive function operates within the expected type constraints.

Recursion is crucial in **Divide and Conquer** and **Greedy Algorithms**:

- **Divide and Conquer**: Breaks a problem into subproblems, solves them recursively, and then combines the results.
- **Greedy Algorithms**: Solves the problem step-by-step, choosing the optimal solution at each step, which can sometimes involve recursion for backtracking purposes.

## 2. Code Examples

### Example 1: Divide and Conquer (Merge Sort)

Merge Sort is a classic example of a divide-and-conquer algorithm. It recursively splits an array into halves, sorts each half, and then merges them.

```typescript
/**
 * Recursively sorts an array using the Merge Sort algorithm.
 * @param arr - The array to be sorted.
 * @returns A new array that is sorted.
 */
function mergeSort(arr: number[]): number[] {
  if (arr.length <= 1) return arr;

  const mid = Math.floor(arr.length / 2);
  const left = mergeSort(arr.slice(0, mid));
  const right = mergeSort(arr.slice(mid));

  return merge(left, right);
}

/**
 * Merges two sorted arrays into one sorted array.
 * @param left - The left sorted array.
 * @param right - The right sorted array.
 * @returns The merged sorted array.
 */
function merge(left: number[], right: number[]): number[] {
  const sortedArray: number[] = [];
  let i = 0,
    j = 0;

  while (i < left.length && j < right.length) {
    if (left[i] < right[j]) {
      sortedArray.push(left[i++]);
    } else {
      sortedArray.push(right[j++]);
    }
  }
  return sortedArray.concat(left.slice(i)).concat(right.slice(j));
}

console.log(mergeSort([34, 7, 23, 32, 5, 62])); // Output: [5, 7, 23, 32, 34, 62]
```

**Explanation**:
The `mergeSort` function splits the array into halves until it reaches a base case (an array of one element). It then merges each half in sorted order using the `merge` function.

### Example 2: Greedy Algorithm (Recursive Change-Making Problem)

In this example, we use a recursive greedy approach to solve the Change-Making problem, where we aim to minimize the number of coins used to make a specific amount.

```typescript
/**
 * Finds the minimum number of coins required to make a given amount.
 * @param coins - Available coin denominations.
 * @param amount - The total amount to make.
 * @returns The minimum number of coins needed to make the amount or -1 if it’s not possible.
 */
function minCoins(coins: number[], amount: number): number {
  // Base case: If amount is 0, no coins are needed
  if (amount === 0) return 0;
  // Base case: If amount is negative, no solution exists
  if (amount < 0) return -1;

  let result = Infinity;

  for (let coin of coins) {
    const subResult = minCoins(coins, amount - coin);
    if (subResult >= 0 && subResult < result) {
      result = subResult + 1;
    }
  }

  return result === Infinity ? -1 : result;
}

const coins = [1, 2, 5];
console.log(minCoins(coins, 11)); // Output: 3 (5 + 5 + 1)
```

**Explanation**:
The `minCoins` function recursively attempts to find the smallest number of coins required by choosing a coin and then finding the result for the reduced amount.

### Example 3: Recursion (Factorial Calculation)

A simple example that demonstrates basic recursion in TypeScript.

```typescript
/**
 * Recursively calculates the factorial of a given number.
 * @param n - The number to calculate the factorial of.
 * @returns The factorial of the number.
 */
function factorial(n: number): number {
  if (n <= 1) return 1;
  return n * factorial(n - 1);
}

console.log(factorial(5)); // Output: 120
```

**Explanation**:
The `factorial` function multiplies the number by the factorial of the previous number until it reaches the base case (`n <= 1`). TypeScript’s type system ensures that `n` remains a number throughout.

## 4. Practical Use Case

### Use Case: Tree Traversal (Depth-First Search)

Recursion is ideal for tree structures, like file systems or organizational charts. You can recursively traverse the nodes of a tree and process them as needed.

```typescript
interface TreeNode {
  value: number;
  children?: TreeNode[];
}

/**
 * Recursively traverses a tree in a depth-first manner.
 * @param node - The current node in the tree.
 */
function depthFirstSearch(node: TreeNode): void {
  console.log(node.value);
  if (node.children) {
    node.children.forEach(depthFirstSearch);
  }
}

const tree: TreeNode = {
  value: 1,
  children: [
    { value: 2 },
    { value: 3, children: [{ value: 4 }, { value: 5 }] },
  ],
};

depthFirstSearch(tree); // Output: 1 2 3 4 5
```

**Explanation**:
The `depthFirstSearch` function is ideal for tree traversal. It prints each node’s value and recursively visits each child node.

## 5. Common Mistakes and Best Practices

### Common Mistakes

1. **No Base Case**: Forgetting to define a base case can cause infinite recursion.
2. **Excessive Stack Usage**: Deep recursive calls can cause stack overflow errors. Consider using iterative methods or tail recursion when possible.
3. **Mismanaging Return Values**: Ensure correct handling of return values in recursive calls, as errors can propagate through recursive calls, leading to unexpected results.

### Best Practices

1. **Identify and Define Base Case**: Always ensure a clearly defined base case to terminate recursion.
2. **Use Tail Recursion Optimization**: For large input sizes, TypeScript can optimize tail recursion to prevent stack overflow.
3. **Consider Memoization**: For overlapping subproblems, like in the Fibonacci sequence, use memoization to optimize recursive calls.
